**X64 热更 · 方案 1（已绿）**  
- UEFI Boot Order #1 = Blocks **U 盘**；`deploy-nuc-usb` / `ksend --path D:Kernel.elf`。  
- **认卷**：`BLOCKS.ID` = 首行 `Blocks root volume` + 次行 `USB`/`SSD`；卷 `D:`=USB bootdisk。  
- 真机：`TryGetByte`→软环；差量 `written=1`；全量（先 `rm D:Kernel.elf`）`written=740` / `crc=f6efe0dc`。**不做** grub 链。

**Pi Arasan / Sdhost（2026-11-02）**  
- µSD 块 = `BoardSdhostRegister`（读写绿）。  
- Arasan = WiFi SDIO（`SdhciHostPrepare` + MMIO）；块死桩已删。
