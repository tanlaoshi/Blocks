# 三架构进度（以 X64 为标杆）

> **日期**：2026-10-28（board-debt 柱收官后）。  
> **标杆**：`ARCH=x86_64` 桌面真机（NUC / UEFI + xHCI + PCI）。  
> **对照靶**：Arm64 → `BOARD=rpi-3b`（Pi 3B）；RiscV → `BOARD=milk-v-duo-s`（Milk-V Duo S）。  
> **另**：两架构均有 `BOARD=virt`（QEMU）做课桌冒烟；本表**真机能力**以板包为准，virt 另注。  
> **活 ★ / 刀序**：见 [`路线图1028.md`](路线图1028.md)。

## 一句话

| 架构 | 相对 X64 | 一句话 |
| --- | --- | --- |
| **X64** | 标杆 100% | UEFI 桌面全栈：键鼠 / 存储 / 有线+iwl WiFi / 板载 BT 课轨 / HDA / GOP |
| **Arm64 · Pi** | **约 55–65%** | 串口+HDMI 上滚、USB 键鼠网、µSD、LwIP DHCP 已通；**无 WiFi / 无 BT 真路径**；无 PCI 桌面外设族 |
| **RiscV · Duo** | **约 45–55%** | 串口壳、USB 键鼠、板载有线+LwIP、µSD 已通；**无真机 FB/桌面**；**无 WiFi / 无 BT**；无 PCI/音频/GPU 族 |

> 百分比是**课堂可感能力**粗估（非代码行数）。共享 `Services/`（Gui/Shell/Store…）三架构同编；差在 **HAL + 板包**。

## 代码形态（为何不是「抄 X64 Drivers」）

| | X64 | Arm64 | RiscV |
| --- | --- | --- | --- |
| **外设主战场** | `HAL/X64/Drivers/**`（~200+ `.c`） | `HAL/Arm64/Board/<board>/**` | `HAL/RiscV/Board/<board>/**` |
| **板包** | 无（桌面 PCI） | `rpi-3b` + `virt` | `milk-v-duo-s` + `virt` |
| **网栈端口** | `HAL/X64/LwIp/` | `HAL/Arm64/LwIp/`（对表） | `HAL/RiscV/LwIp/` |
| **蓝牙门面** | 接 xHCI BT | stub Ready=0 | stub Ready=0 |

板端把 USB/ETH/SD 做在 **Board/**，不复制 X64 的 xHCI/AHCI/iwl 树——这是刻意分层，不是「少写了同名驱动文件」。

## 相对标杆：缺什么（按优先级）

### Arm64 · Pi（先补这些才接近课桌观感）

1. **WiFi**（pwifi-1…3）— SDIO / BCM43455 → 扫 AP → ping；其后 **pi-smp**（4×A53）  
2. **BT**（bt-pi）— UART HCI + 固件；勿与调试串口硬抢  
3. **桌面稳态** — 真机 Gui/键鼠/中文与 X64 同形验收（现有 FB+HID 上再磨）  
4. 不追求：PCI NIC 族、HDA、iGPU、NVMe

### RiscV · Duo

1. **真机显示**（若要桌面课轨）— 现 `HAS_FRAMEBUFFER=0`，课桌靠 `virt`  
2. **WiFi**（dwifi-1…3）— 先钉总线再扫连  
3. **BT**（bt-duo）— 先探针有无芯  
4. 不追求：与 X64 同款存储/音频/GPU

### 已对齐、不必再当「进度差」

- 串口 BringUp / 壳命令（含大小写不敏感）  
- LwIP 有线：DHCP / ping（Pi、Duo 均已收官）  
- USB HID + 板载/USB 有线以太网  
- µSD 根文件系统路径  
- board-debt：拆分 ≤300 + 公开命名（`BoardUsbHostController*`）
