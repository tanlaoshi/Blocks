# Blocks 应用开发指南

> 写用户态 ELF、进 Guest 跑、可选上商店。  
> ABI / 版本以 [`开课ABI冻结.md`](开课ABI冻结.md) 为准；函数表见 [`API速查.md`](API速查.md)。  
> Shell：`blocks>` · 卷：`BLOCKS:` · CRT **1.5.0** · UI/Graphics/Net **3.0.0**。

---

## 一、你在改什么

用户程序是 **静态链接的 ELF**，链 `libcrt.a`（及需要的 `libUi` / `libGraphics` / `libNet` / `libVolumePath`），经 syscall 进内核。  
**不要**链宿主 libc，**不要** `-pie`。

推荐入口：

| 方式 | 路径 | 用途 |
| ---- | ---- | ---- |
| 离树 SDK 示例 | `Kernel/Tools/Sdk/Examples/{Hello,Gui,Net}` | 作业 / 最小复现 |
| 树内 Demo | `Kernel/User/Apps/*Demo.c` | 随 `build` 进镜像 |
| 接手总览 | [`开发者接手指南.md`](开发者接手指南.md) | 内核向 |

## 二、环境与构建

```bash
source ~/Blocks/env.sh          # 仓根；得到 build / run / …
build                           # 编内核 + 默认同步 rootfs（x64）
run                             # QEMU；看串口
```

离树 Hello：

```bash
source ~/Blocks/env.sh
cd "$KERNEL/Tools/Sdk/Examples/Hello"
make                            # 产出 build/*.ELF（以该目录 Makefile 为准）
```

把 ELF 放进客户机可见 FAT（常见：`Runtime` / `Image` 的 RootFs 约定，或 `Assets/Store/packages/` 商店包），再：

```text
blocks> exec HELLO.ELF
```

盘名习惯：**8.3 大写**（`MYAPP.ELF`）。路径可用 `BLOCKS:MYAPP.ELF` 或已挂载卷上的相对名。

核对格式：

```bash
file build/HELLO.ELF
# 期望：ELF 64-bit … x86-64（课机 x64）
readelf -h build/HELLO.ELF
```

## 三、最小程序（CRT）

```c
#include <stdio.h>
#include <Blocks/version.h>

int main(void) {
    printf("hello Blocks CRT %s\n", CRT_VERSION_STRING);
    return 0;
}
```

`printf` 在焦点落在用户窗时往往**只走串口**——没输出先看 QEMU 串口，不要只盯窗口客户区。

### 进程

```c
#include <unistd.h>
#include <sys/wait.h>
#include <stdio.h>

int main(void) {
    pid_t p = fork();
    if (p == 0) {
        printf("child\n");
        return 7;
    }
    int st;
    wait(&st);
    printf("parent: exit=%d\n", WEXITSTATUS(st));
    return 0;
}
```

注意：`wait` **不是** `waitpid`；退出码在 CRT 里左移 8 位（用 `WEXITSTATUS`）。

### 文件红字

- `fopen("w")` **不截断** → 先 `remove(path)` 再 `fopen`。  
- `write` 返回 **0** 当作错误（`read` 的 0 才是 EOF）。

```c
remove("NOTE.TXT");
FILE *f = fopen("NOTE.TXT", "w");
/* … */
```

卷路径助手（FsUtil **2.0**）：

```c
#include <VolumePath.h>
char Path[FS_PATH_MAX];
FsUtilBlocksPath(Path, sizeof Path, "NOTE.TXT");  /* → BLOCKS:NOTE.TXT */
```

目录：`<dirent.h>` 的 `OpenDirectory` / `ReadDirectory`，或 `FsUtilListDir`。

## 四、GUI（UI 3.0）

链 `libUi.a`。示例真源：`Tools/Sdk/Examples/Gui/main.c`。

```c
#include <stdio.h>
#include <unistd.h>
#include <sched.h>
#include <Ui.h>

int main(void) {
    int Wid = UiCreateWindow("MyGui", 400, 240);
    if (Wid < 0) {
        printf("create fail\n");
        return 1;
    }
    UiSetLabel(Wid, "Hello GUI");
    UiAddButton(Wid, 0, "OK");

    for (;;) {
        int Ev = UiPoll(Wid);
        if (Ev == UI_EVENT_CLOSE) {
            break;
        }
        if (Ev == UI_BUTTON_EVENT(0)) {
            UiSetLabel(Wid, "OK!");
        } else if (Ev == UI_EVENT_NONE) {
            sched_yield();
        }
    }
    return 0;
}
```

需要像素绘制时再链 `libGraphics.a`，用 `GraphicsDamageText` / `GraphicsDraw*`（见 `Graphics.h`）。  
**禁止**旧 GUI syscall 18–21。

窗口槽有上限；创建失败先关其它窗。示例：`Tools/Sdk/Examples/Gui/main.c`。

## 五、网络（Net 3.0 · 需 lwIP）

Guest 先：`lwip on`。宿主机可 `nc -l -p 8888`。

**只教** `NetConnect` / `NetBind`（**主机序**，`NetIpv4`）。不教 `sockaddr` / `htons`。

```c
#include <stdio.h>
#include <Net.h>
#include <Blocks/File.h>

int main(void) {
    int Fd = socket(AF_INET, SOCK_STREAM, 0);
    if (Fd < 0) {
        printf("socket fail\n");
        return 1;
    }
    if (NetConnect(Fd, NetIpv4(10, 0, 2, 2), 8888) != 0) {
        printf("connect fail\n");
        FileClose(Fd);
        return 1;
    }
    send(Fd, "hi\n", 3, 0);
    FileClose(Fd);
    printf("ok\n");
    return 0;
}
```

模板：`Tools/Sdk/Examples/Net/main.c`。  
Arm64/RiscV virt 常见 `LWIP=0`，无此课端口。

跨机聊天协议 / 端口见柱规格「局域网商店与聊天」（若课程启用）。

## 六、线程子集（非完整 pthread）

```c
#include <Blocks/thread.h>
/* 或 #include <pthread.h> — mutex 为自旋教学版 */
```

自测（镜像含 Demo 时）：`blocks> exec THREADDEMO.ELF`。  
任务列表同源：`#include <Blocks/task.h>` → `blocks_task_snap`（见任务管理器课堂作业）。

## 七、调试

| 现象 | 先查 |
| ---- | ---- |
| `exec` 找不到文件 | ELF 是否在可见 FAT；名是否 8.3 大写；`ls` / `vols` |
| 有 exec 无输出 | 串口（`printf` 不进窗） |
| 立刻退出 | `main` 返回值 / 开头 `printf` 卡点 |
| `open` = -1 | 路径 / 卷前缀 `BLOCKS:` |
| `socket` = -1 | `LWIP`、是否 `lwip on` |
| 返回 -38 | 未知 syscall / 旧 GUI 号 → 查 `SyscallABI.h` |

## 八、打包与安装（商店目录包）

| 路径 | 做法 | 定位 |
| ---- | ---- | ---- |
| A 捷径 | `cp` ELF 到 RootFs → `exec NAME.ELF` | 5 分钟 Hello |
| B 正统 | `Assets/Store/packages/<id>/` + `catalog.txt` → `store combo` | 打包课默认 |

`PKG.TXT` 最小例：

```text
name=myapp
type=app
version=1
file=MYAPP.ELF
sha256=-
arch=x86_64
title=My App
desktop=yes
taskbar=yes
```

`catalog.txt` 追加一行后随镜像同步；Guest：

```text
store combo myapp
exec Apps/myapp/MYAPP.ELF
```

卸装：`store uncombo` / `store remove`。扁平 `Apps/*.ELF` 遗留勿再新增。

## 九、FAQ 速答

1. **file not found** — 未进 rootfs / 店包；检查 `prepare`/`build` 同步与文件名。  
2. **fork 子无输出** — 看串口；父要 `wait`。  
3. **GUI 创建失败** — 窗口槽满或未链 `libUi.a`。  
4. **未知 syscall** — `-ENOSYS`；勿手写号。  
5. **还缺什么** — 见冻结表「不承诺」；已有勿再催：`getpid`、`sched_yield`、`NetConnect`、线程子集、`-ENOSYS`。
