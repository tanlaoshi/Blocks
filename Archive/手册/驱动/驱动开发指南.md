## 1. 五分钟概念

| 概念 | 含义 |
| --- | --- |
| `DriverRegister` | 只把驱动放进表；**不上线** |
| `DriverProbeClass` / `DriverProbeAll` | 调 `Probe`；成功再 `Bind`；`Bound=1` 后 `lsdev` 可见 |
| `DRIVER_BOOT` | 驱动自己挂启动表；`HalDriverRegister()` 按 `Order` 调用，**不必改** `HalDevices.c` |
| Backend | Input / Block / Net 的真实 ops；真驱动在 **Bind** 里 `Driver*Attach` 或 `NetAttachNic` |
| `Match` | `NULL` = Probe 自扫；非 `NULL` = 表驱动（框架过滤 `DEVICE_NODE`） |

启动链（x86）：链接段收集 `DRIVER_BOOT` → `HalDriverRegister()` 按序登记 → 早期 Probe **BLOCK** → VMM 后再 Probe **INPUT / NET / …**。

命名：类型与 API 前缀是 **`DRIVER` / `Driver*`**（不要再写 `ToyDriver*` / `TOY_DRIVER`）。

## 2. 目录规则（写死）

根：`Kernel/HAL/<Arch>/Drivers/`（x86 以 `HAL/X64/Drivers/` 为准）。

| # | 规则 |
| - | ---- |
| 1 | **新设备**落在已有分层夹下的子目录，**禁止**新增 `Drivers/` 根级业务 `.c`（遗留 `DemoDriver.c` 除外） |
| 2 | **分层夹**：`Bus/`（XHCI/Ehci/Uhci/Hub）、`Input/`（Ps2、UsbHid）、`Block/`（Ahci/Ata/Nvme）、`Model/`（E1000/Alx/Rtl*/Iwl/VirtioNet）、`Network/`（协议核）、`Video/`、`Hda/`、`Msc/`、`Serial/` |
| 3 | USB 类驱动优先只依赖主机控制器门面；键鼠在 `Input/UsbHid/`，控制器实现在 `Bus/XHCI/` 等 |
| 4 | Net L2 胶水进 `Model/<Nic>/`；`Drivers/Network/` 留协议核（ARP/地址等） |
| 5 | Virtio MMIO 继续 `HAL/Virtio/`；X64 PCI virtio 胶水跟 `Model/VirtioNet/` |
| 6 | 设备私头进设备目录；公开门面在 `Include/Driver/` |

**编入**：`Makefile` 的 `DRIVER_SRCS` 对已知子目录做 `wildcard`。**新建**一层目录时须加一行，例如：

```make
DRIVER_SRCS += $(wildcard HAL/$(HAL_ARCH)/Drivers/Model/<MyNic>/*.c)
```

`_template/` **永不**编入。

## 3. 写一个驱动（5 步）

1. **复制** `_template/Template.c` → `HAL/X64/Drivers/<层>/<MyDevice>/MyDriver.c`  
   - 不要留在 `_template/`；不要丢到 `Drivers/` 根。  
2. **改名**：`Name`、`Template*` / `gTemplate*` 前缀、`MyDriverRegister`。  
3. **实现 `Probe`**：有设备 `return 0`；否则非 0。模板默认 `-1`（故意不上线）。  
4. **挂启动表**（两处）：  
   - 在 `Include/Driver/DriverBoot.h` 增加一个未占用的 `DRIVER_BOOT_*` 序值；  
   - 在驱动 `.c` 末尾：`DRIVER_BOOT(DRIVER_BOOT_MY, MyDriverRegister);`  
   - 新目录：补 Makefile `wildcard`。  
5. **验证**：

```bash
cd Kernel && ./build.sh
cd ../Runtime && ./run.sh --headless   # 或带显示的 ./run.sh
# Shell：lsdev 应见 my-driver …
# 串口可有 driver: registered=… bound=…
```

## 4. 课堂 Demo（默认开启）

| 项 | 行为 |
| --- | --- |
| 文件 | `HAL/X64/Drivers/DemoDriver.c`（根级遗留；课堂开关用） |
| `lsdev` | `demo-driver input` |
| Probe / Bind | 串口：`demo: probe …` / `demo: bind called` |
| Backend | **永不** `DriverInputAttach`（不抢键鼠） |
| 匹配 | PCI 表：任意 Intel（`8086` + Device 通配）→ 常命中宿主桥 |

关闭：

```bash
cd Kernel
./build.sh DEMO_DRIVER=0
# 或 make DEMO_DRIVER=0 后确保重链；产物已由 build.sh 同步到 Runtime/RootFs
```

换 `0/1` 后须确认 **重编/重链**（Makefile 有 `DEMO_STAMP`）；再跑 `Runtime/run.sh`，否则仍是旧镜像。

新 PCI 驱动抄 `Model/E1000/NetE1000.c` 的表，不要再写全总线扫描。

## 5. Probe 怎么找设备

| 模式 | 做法 | 参考 |
| --- | --- | --- |
| A 固定口 / 地址 | Probe 内直接访问 | `Input/Ps2/`、`Block/Ata/` |
| B PCI | 填 `DRIVER_MATCH`，`Probe` 用 `BusCtx`（`DEVICE_NODE *`） | `Model/E1000/`、`Block/Ahci/`、`Block/Nvme/` |
| C 软条件 | VMM / 策略位 | `Msc/BlockMsc.c` |

`Match == NULL` 只用于固定口和 USB 类门面等（PS/2、ATA、virtio 自扫、`usb-msc`、部分 wifi）。细则：[`驱动匹配规范.md`](驱动匹配规范.md)。

## 6. Bind 挂哪一类 Backend

| 类 | Bind 调用 | 注意 |
| --- | --- | --- |
| INPUT | `DriverInputAttach(&ops)` | 多为 mux；后挂可与先挂并存或覆盖，视实现 |
| BLOCK | `DriverBlockAttach(&ops)` | 后端指针后挂覆盖（NVMe / AHCI / ATA） |
| NET（**协议门面**） | `DriverNetAttach(&ops)` | **胖** `NET_BACKEND`；一般只由协议核提供一份 |
| NET（**网卡 L2**） | **`NetAttachNic` / `NetAttachNicKind`** | **新网卡走这条**；见下节 |

课堂 Demo 故意不 Attach，只占实例槽给 `lsdev` 看。真驱动必须 Attach 才会驱动硬件。

`Poll` / 中断 **不在** `DRIVER` 上：填 Backend / `NIC_L2` 的 `Poll`，或自接 IRQ（如 xHCI / e1000e MSI）。

## 6.1 网卡驱动（仍是 DRIVER · 走 NIC_L2）

网卡**也是驱动**：同样 `DriverRegister` → `Probe` → `Bind` → `lsdev`，遵守本指南 §2～3、§6。

与键鼠/块设备的差别在 **Bind 挂什么**：

```text
DRIVER (Probe/Bind)              协议栈（Network/ / lwIP）
        │                              ▲
        │ Bind                         │ NetInputFrame / HalNet*
        ▼                              │
   NIC_L2  ops  ──NetAttachNic*()──────┘
   SendFrame / Poll / GetMac [/ GetLink]
```

| 要写 | 不要写 |
| --- | --- |
| `NIC_L2`：`SendFrame`、`Poll`、`GetMac`（可选 `GetLink`） | 整份 `NET_BACKEND`（Ping/SendIp/FormatIp…） |
| Bind 里 **`NetAttachNic` / `NetAttachNicKind`** | Bind 里只 `DriverNetAttach` 自造胖后端 |
| RX 路径调 **`NetInputFrame(pkt, len)`** | 在协议核里加 `if (gMyNic)` 硬分支 |

**活范例**：`HAL/X64/Drivers/Model/E1000/`（以及 Alx / Rtl8168 / Iwl 等）。  
**头文件**：`Include/Driver/DriverNic.h`。  
**拷贝骨架（不进 Kernel）**：`HAL/X64/Drivers/_template/TemplateNetL2.c`。  
**过程笔记**：[`驱动开发范例-网卡L2.md`](../../过程/柱归档/驱动开发范例-网卡L2.md)。

地址 / DHCP（协议栈侧，**不是**网卡驱动本体）：

| 能力 | 入口 |
| --- | --- |
| 静态 IP/GW/DNS | Shell `net config` / `setip` `setgw` `setdns` |
| DHCP | `lwip dhcp` / `net dhcp` |
| 课路径默认 | QEMU：常默认 SLIRP 网段（如 `10.0.2.15/24`） |

virtio-net 在 `Model/VirtioNet/`；**新 PCI/MMIO 网卡不要再仿「改协议核特例」**，一律 `NIC_L2`。

## 7. 常见错误

| 现象 | 原因 |
| --- | --- |
| Register 了但 `lsdev` 没有 | 忘了 `DRIVER_BOOT`；或 Probe/Bind 失败；或未进 `DRIVER_SRCS` |
| Probe=0 仍看不见 | Bind 返回非 0 |
| 改了 `_template/Template.c` 无效果 | 模板不编进内核；必须复制到设备目录 |
| 新业务 `.c` 丢在 `Drivers/` 根 | **违规**；用分层子目录 + Makefile wildcard |
| `DEMO_DRIVER=0` 后 smoke 仍有 `demo:` | 未重链 / 未跑到新 `Runtime/RootFs` 镜像 |
| 开机卡死 | Probe 里硬件死循环；加超时 |
| 网卡 `lsdev` 有、但 ping 不通 | Bind 未 `NetAttachNic*`；或 RX 未调 `NetInputFrame` |
| 新网卡去改 `Network/` 加硬分支 | 违规；应 `NIC_L2` + `NetAttachNic*` |

禁止：把 `_template/` 当真驱动目录；盲目 `Drivers/**/*.c` 把模板扫进链接；**禁止新增** `Drivers/` 根级业务 `.c`。

## 8. 验收速查

```bash
# 模板未链入（精确符号；含 Net L2 骨架）
nm Build/HAL/X64/Kernel.elf | grep -iE \
  'TemplateDriver|gTemplate|TemplateProbe|TemplateBind|TemplatePoll|TemplateNet'
# 期望：空

# Demo 默认开
cd Kernel && ./build.sh
cd ../Runtime && ./run.sh --headless
# 串口应有 demo: probe/bind；Shell lsdev 有 demo-driver

# 网卡 L2（示例）
BLOCKS_NET=e1000e ./run.sh --headless   # 若 run.sh 支持该环境变量；否则改 QEMU 网卡后再手测
# Guest：show network / net config；lwip on → ping 网关
```
