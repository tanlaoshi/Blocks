# 编码规范

> **唯一入口。写新代码只认本文。**
> 命名风格参照 EDK2，规模上限与「不用魔法数」是本项目的硬指标。
> 本文没写的，按本文的原则推；推不出来再问，别自己另立一份。

## 一、命名

### 1. 函数、变量、结构体字段：PascalCase

每个单词首字母大写，词间不加下划线。

| 要 | 不要 |
| -- | ---- |
| `SerialInitialize` | `serial_init` / `serialInitialize` / `Serial_Initialize` |
| `ReceiveMessage` | `RecvMsg` |

### 2. 名词在前，动词在后

先读到「是哪一块、哪件东西」，再读到「它做什么」。层前缀放最前面。

| 要 | 不要 |
| -- | ---- |
| `ConsoleInitialize` | `InitializeConsole` |
| `HalSerialWrite` | `HalWriteSerial` |

### 3. 类型与宏：全大写

| 对象 | 写法 |
| ---- | ---- |
| 类型 | `SDHCI_HOST`、`AIC_PATCH_INFO` |
| 宏 / 常量 | `AIC_CFM_TIMEOUT_MS`、`SDHCI_BLOCK_SIZE` |

### 4. 全局 `gXxx`，文件内静态 `sXxx`

| 作用域 | 前缀 | 例 |
| ------ | ---- | -- |
| 跨文件全局 | `g` | `gAicRx` |
| 仅本文件 static 变量 | `s` | `sRetryCount` |

> EDK2 用 `m`（module）表示模块静态。本项目统一用 `s`（static）——在 C 里 `s` 比 `m` 更直白。
> **新代码一律 `s`**，不再引入 `m`。

### 5. 写全名，尽量不用缩写

判断标准：**这个缩写能不能还原成一个完整单词？**
能，就必须展开；不能，它是正式名字，保留。

| 不要 | 要 |
| ---- | -- |
| `Cfg` | `Config` |
| `Idx` | `Index` |
| `Buf` | `Buffer` |
| `Blk` | `Block` |
| `Tbl` | `Table` |
| `Ctx` | `Context` |
| `Hc` | `HostController` |
| `Mgr` | `Manager` |
| `Ptr` | `Pointer` |
| `Msg` | `Message` |
| `Len` | `Length` |
| `Val` | `Value` |
| `Addr` | `Address` |
| `Dst` / `Src` | `Destination` / `Source` |
| `Cur` | `Current` |
| `Tmp` | `Temporary` |
| `Cnt` | `Count` |

**保留的缩写**（是正式名字，不是砍短的单词）：
`USB` `PCI` `SDHCI` `SDIO` `DMA` `IRQ` `CPU` `GPU` `MAC` `PHY` `RF` `CRC` `IPC`
`API` `ABI` `HAL` `FIFO` `NVRAM` `EFI`；
以及厂商/协议原名：`AIC` `RWNX` `LMAC` `TASK_MM` `TASK_DBG`。

### 6. 文件与目录

- 文件、目录都用 PascalCase：`Sdhci/Command.c`、`Gui/WindowManager/`。
- **主文件与目录同名**：`XHCI/Xhci.c`、`Serial/Serial.h`。
- **辅助文件不重复模块名**：`XHCI/UsbHostController.c` 不叫 `XhciUsbHostController.c`。
- **函数名不重复文件名**：文件已经说明是哪一块，函数只写它自己的动作。
- **辅助头统一叫 `Private.h`**；同目录已有一个 `Private.h` 时，用 `模块名Private.h`
  （例：`Sdhci/WifiPrivate.h`）。

### 7. 短函数名进操作表

内核一次链接，全局只有一张符号表。`Write`、`Initialize` 不能各有一份全局函数。

- 一个模块对外**一张操作表**，表字段用短名；
- 真正干活的函数写 `static`，别的目录通过这张表调用；
- 会在别的模块撞名的全局函数，不靠加前缀躲，收进表里。

### 8. 日志文案就是验收判据

串口里打出来的字符串，和验收标准写的是同一句。改文案等于改判据，要一起改。

## 二、规模上限

| 对象 | 上限 |
| ---- | ---- |
| 任意函数 | **60 行** |
| 主函数（顺序表：只编排、不做事） | 30 行 |
| 主文件对外 API（薄包装） | 15 行 |
| 任意 `.c` | **300 行** |
| 任意 `.h` | 300 行 |

**新代码超标必须先拆再写。** 存量超标按模块分刀，不一次翻全库。

**例外**：`ThirdParty/`、点阵/字体数据、构建脚本、`Archive/**` 的文档。

### 拆分形态固定为「1 个核心文件 + 多个辅助文件」

| 核心文件 | 辅助文件 |
| -------- | -------- |
| `Console.c` | `ConsoleWrite.c` / `ConsoleScroll.c` / `ConsoleCommand.c` |
| `WifiFw.c` | `WifiMessage.c` / `WifiMemory.c` / `WifiPatchTable.c` … |

**拆文件三条铁律**：

1. **纯搬家**，函数体逐字不动；
2. **这一刀不改名**（搬家和改名分开，否则 diff 无法审查）；
3. **每搬一个就编译一次**，不许全搬完再编。

## 三、数字与错误要露脸

- **不用魔法数**。寄存器偏移、超时、尺寸、协议常量，一律起名：

  | 不要 | 要 |
  | ---- | -- |
  | `if (X > 120)` | `if (X > AIC_RX_MESSAGE_THRESHOLD)` |
  | `0x40500150` 散落在代码里 | `#define AIC_RESET_ADDRESS 0x40500150u` |

- 常量旁边写**出处**（手册章节、厂商文件:行号）。半年后没人记得 `120` 是哪来的。
- 可能失败的调用：**处理错误**，或显式 `(void)` 表示有意忽略。不许静默吞掉。
- 语义值不要裸比较：`state == 2` 改成 `state == AIC_PATCH_POISONED`。

## 四、注释

### 文件头说清三件事

```c
/*
 * 人话：这文件在用户眼里是什么（一句话场景）。
 * 从哪读：按顺序列 2~4 个函数名。
 * 别改：和别人的契约（ABI / 顺序 / 锁 / 协议字段），可选。
 */
```

### 注释写「为什么」，不写「做了什么」

- 代码已经说了「做了什么」，注释只补它说不出来的：为什么这么写、踩过什么坑、和谁有契约。
- 允许写「试过 A 不行，因为 B」——这类信息代码里没有。
- 禁止：逐行复述代码；把提交号当唯一说明；标识符写拼音。

---

## 五、分层

依赖方向单向：

```
User → Services → Core → Library → HAL → Boot
```

- 上层只通过门面调下层；
- `Common` / `Include` / `User` **不**直接 include 某架构的 `HAL/.../Drivers/...`；
- 板级差异走**能力旗标**，不在共享层堆 `BOARD_` ifdef。

---

## 六、Kernel 方言

自有树（`Core/Services/HAL 自研/Library/Include/User`）锁 **ISO C99 `-pedantic`**。

- 不写 `_Static_assert`、手写 `__attribute__`、`__builtin_*`、`__sync_*`；
- 垫片只在 `Include/Abi/Compiler.h` 与 `Include/Abi/Atomic.h`；
- 例外：`Boot/`（跟 EDK2）、`ThirdParty/`、lwIP、FreeType。

---

## 七、怎么执行

1. **新代码守规矩**；旧代码**路过再改**，不要求一次翻全库。
2. 点到哪个文件，顺手把眼前的命名、注释、魔法数收干净，**行为不变**。
3. 拆完必须验证：编译 + 回归 + **该上真机的上真机**。拆文件不是「编过就算」。
4. 一次改动跨三个文件，说明模块边界划错了 —— 先改边界，再改代码。

## 八、与 EDK2 的对照（参考，不是照搬）

| 项 | EDK2 | 本项目 |
| -- | ---- | ------ |
| 函数 / 变量 | PascalCase | 同 |
| 全局 | `gXxx` | 同 |
| 模块静态 | `mXxx` | `sXxx` |
| 类型 | `EFI_` 前缀 + 全大写 | 全大写，不强制前缀 |
| 宏 / 常量 | 全大写 | 同 |
| 缩进 | 2 空格 | **4 空格** |
| 参数方向 | `IN` / `OUT` 宏 | 不写 |
| 函数头注释 | Doxygen | 中文人话文件头 |
| 注释语言 | 英文 | **中文** |
