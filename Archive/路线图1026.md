## 1 · duo-net · Duo 以太网 <a id="duo-net"></a>

> **承接**：1025 duo-next（usb-kbd ✅；slim ⛔）。板上有口，仓内 **无** 真机 MAC 驱动。  
> **硬件**：DTB `ethernet@4070000`（`cvitek,ethernet` / stmmac·DWMAC 系）。  
> **上栈**：真机 `cv181x-ethernet` → `HalNet*`（net-4/5 ✅）；lwIP/DHCP → [net-6](#net-6)。  
> **不做混进一刀**：与 sd-write / USB / Pi 加固搅同一 PR；空 stub 顶「有网」。  
> **序**：net-1 → … → net-5 → net-6（单变量；前刀不过不点后刀）。

| 刀 | 用户能感到什么 | 主战场 | 验收 | 手测 | 风险 |
| --- | --- | --- | --- | --- | --- |
| **[net-1](#net-1)** | 串口证明 eth 控制器活 | 板 `Ethernet*`；clk/reset；对表 U-Boot/Linux cv181x | `Boot: Duo ETH …`；版本/ID 对规格 | Duo + 可不插线 | 中：基址/时钟 |
| **[net-2](#net-2)** | 插线 link | MDIO + PHY | 串口 `link up`（或等价） | Duo + 网线 | 中～高：PHY 型号 |
| **[net-3](#net-3)** | 帧能进能出 | DMA 环；Sv39 cache | 自发自收或抓包见帧 | Duo | **高**：DMA 一致性 |
| **[net-4](#net-4)** | 栈认这块 NIC | `HalNetInitialize` 真机路径；勿走 VirtioNet | `HalNetReady`；与 virt 门面同形 | Duo | 中：门面契约 |
| **[net-5](#net-5)** | **静态能 ping** | ARP/ICMP；`setip` | ping 通网关 | Duo | 中：线缆 DMA |
| **[net-6](#net-6)** | **DHCP 拿地址** | RiscV lwIP 端口；`net dhcp` | dhcp 后 ping | Duo | **高**：lwIP 移植 |

### net-1 · MAC 探针 <a id="net-1"></a>

✅。时钟 / 复位 / MMIO 探针。

- [x] 对表：`0x04070000`；mainline `dwmac-3.70a` → **VERSION @0x20**（实测 `ver=00001037`；`@0x110`=0）  
- [x] `BoardEthernetProbe`（`Ethernet.c`）→ `Boot: Duo ETH id=3.70a@20 ver=…`；NOTES 已钉  
- **禁止**：未探针先开 DMA；猜基址；本刀不改 `BOARD_HAS_NET`

### net-2 · PHY / link <a id="net-2"></a>

✅ 真机（2026-10-26）。依赖 net-1。

- [x] MDIO：`GMAC_MII_*`；EPHY 交 MAC；扫 addr（优先 1）  
- [x] 串口 `phy=1 id=00435649` · `bmsr=79ed` · `lpa=cde1` · `aneg=1` · **`link=up`**  
- **禁止**：无 link 假称 Ready；本刀不开 DMA / 不改 `BOARD_HAS_NET`

### net-3 · DMA 收发 <a id="net-3"></a>

✅ 真机（2026-10-26）。依赖 net-2。

- [x] TX/RX **normal** 描述符环（`dmafeat=420d5925` ENHDESSEL=0）；对表 `dwmac_dma` / `descs.h`；MAC LM 环回  
- [x] `HalDcacheCleanInvalidateRange`（skip-MMU 下仍 VA==PA，同 USB DMA）  
- [x] 串口 `enh=0 normal` · **`DMA tx=ok`** · **`rx=ok len=00000044`**  
- **禁止**：无证据缩超时 / 盲重试风暴；本刀仍 **`BOARD_HAS_NET=0`**

### net-4 · HalNet 门面 <a id="net-4"></a>

✅ 真机（2026-10-26）。依赖 net-3。

- [x] `BOARD_HAS_NET=1`；`BoardEthernetRegister` → Bind → `DriverNetAttach`；**不** `VirtioNetRegister`  
- [x] ConsoleOnly：`gModulesVirt` Network → `HalNetInitialize`（无 Worker）  
- [x] LM 自检后关 LM 常驻；串口 **`DMA wire`** · **`ETH bind`**  
- **禁止**：半截 API；空函数声称有网

### net-5 · ping / 套接字 <a id="net-5"></a>

✅ 真机（2026-10-26）。依赖 net-4。

- [x] 静态 `setip`；ARP + ICMP（对齐 Virtio）；串口壳 `HalNetPoll`；VirtMin 挂 `net`/`ping`  
- [x] LM 后 **`DmaStartWire`**（按 LPA 重配 MAC）；真机 **`ping 192.168.31.1` → reply**  
- [x] DHCP **本刀不做**（RiscV `LWIP=0`）→ [net-6](#net-6)  
- **备注**：课堂「静态能 ping」以本刀为准；DHCP 观感见 net-6

### net-6 · LwIp / DHCP <a id="net-6"></a>

✅ 真机（2026-10-26）。依赖 net-5。柱验收。

- [x] `HAL/RiscV/LwIp/`（对表 X64）；编核 `LWIP=1`；`LibcStub` atoi  
- [x] `BoardEthernetSendFrame` + RX→`LwIpNetifInput`；`HalNetPoll`→`LwIpService`  
- [x] ConsoleOnly 串口壳 `LwIpDhcpStep`（无 Worker）；`lwip on` / **`net dhcp`**  
- **禁止**：无端口却挂 `net dhcp` 门面；启发式缩超时碰运气

## 2 · rpi-harden · 3B+ EL1 / MMU <a id="rpi-harden"></a>

> **承接**：[1024 rpi-desk](路线图1024.md#rpi-desk) → [1025](路线图1025.md) 交棒本档。主线桌面已过；本档只收 **rpi-8 / rpi-9**。  
> **稳态**：EL1 + 恒等 MMU（外设 Device）+ mailbox FB + 键鼠 + TTF。  
> **历程**：[Pi3BPlus真机启动排障历程.md](过程/排障/Pi3BPlus真机启动排障历程.md)。

### rpi-8 · EL2 → EL1 <a id="rpi-8"></a>

✅ TG（2026-10-27）。`SP_EL1` + 恒等 MMU；手测 `EL=1` / `MMU on` / 桌面+`blocks>`；花屏交 rpi-9。

- [x] 对照 ARM ARM：`SCTLR_EL1` RES1、`HCR.RW`、`CNTHCTL`/`CPTR`、**`SP_EL1`**（EL1h）  
- [x] 信标：`*` → `+`；串口 `Boot: EL=1`  
- [x] EL1 须开恒等 MMU（off→Device→alignment halt）  
- 附：`ck-pi-sd` 内 prepare；ShellOwn 后 Log→RUNTIME；boot 字 id0 稳定

### rpi-9 · 真机 MMU 属性收口 <a id="rpi-9"></a>

✅ TG（2026-10-27）。手测：`FB-WC OK (MAIR Attr1 Device)`、桌面不花屏；开机日志略闪可另刀。rpi-harden 收官。

- [x] 去掉 `vmm: skip MMU (board)`；恒等 + `0x3F000000` Device（随 rpi-8）  
- [x] FB 页属性与 mailbox 缓冲一致（`HalVideoEnableFbWc` → Attr1 Device）  
- [x] 自测失败只打串口（EL1+VBAR 探针）  
- **禁止**：无证据缩超时 / 跳自测装过关  

与 Duo [duo-mmu](路线图1025.md#duo-mmu) **分刀**（Arch/板不同）；经验可对照，代码勿搅。
