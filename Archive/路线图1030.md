### 5.0 一次性采集（先跑这个，省事）

```sh
{
  echo "== 5.1 =="; uname -a
  ls -l /sys/bus/sdio/devices/ 2>/dev/null
  for d in /sys/bus/sdio/devices/*; do echo "$d v=$(cat $d/vendor 2>/dev/null) d=$(cat $d/device 2>/dev/null)"; done 2>/dev/null
  lsusb -t 2>/dev/null | head -20
  lsmod
  dmesg | grep -iE "aic|8800|8723|8189|cfg80211|sdio" | head -40
  echo "== 5.2 =="; ls -l /lib/firmware/ | grep -iE "aic|8800|rtl|brcm|fw"
  md5sum /lib/firmware/*8800* /lib/firmware/*aic* 2>/dev/null
  echo "== 5.3 =="; zcat /proc/config.gz 2>/dev/null | grep -iE "AIC|8800|CFG80211|MAC80211|MMC_SDIO"
  ls /lib/modules/$(uname -r)/kernel/drivers/net/wireless/ 2>/dev/null
  echo "== 5.4 =="; grep -i mmc /proc/interrupts; cat /sys/kernel/debug/mmc1/ios 2>/dev/null
  echo "== 5.5 =="; cat /proc/cmdline; free -m; head -3 /proc/cpuinfo
```

### 5.3 Linux 驱动形态（fullmac 还是 softmac）

```sh
zcat /proc/config.gz 2>/dev/null | grep -iE "AIC|8800|CFG80211|MAC80211|MMC_SDIO"
ls /lib/modules/$(uname -r)/kernel/drivers/net/wireless/ -R | head -30
modinfo aic8800_fdrv 2>/dev/null | head -20
```

**判据**：`lsmod` 里出现 `mac80211` → softmac（管理帧要在内核里跑，活多）；
只有厂商单个模块 → fullmac（我们只需搬数据帧）。

### 5.4 设备树里的电源 / 时钟 / reset

```sh
dtc -I fs -O dts /sys/firmware/devicetree/base 2>/dev/null > /tmp/duo.dts
grep -niE "wifi|wlan|sdio|mmc|regulator|clock" /tmp/duo.dts | head -40
grep -i mmc /proc/interrupts
cat /sys/kernel/debug/mmc1/ios 2>/dev/null
```

没有 `dtc` 时用：

```sh
ls /proc/device-tree/ | head -20
hexdump -C /proc/device-tree/wifi*/compatible 2>/dev/null
```

**判据**：WiFi 芯片通常要单独的电源轨 / 32k 时钟 / reset GPIO。不供电，SDIO 枚举是空的。
