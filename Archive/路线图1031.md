## pi-sd · µSD 写（落盘证据） <a id="pi-sd"></a>

> **为何插在 WiFi 前**：无串口/屏滚不全时，唯一复现手段是插回读 LOG；写桩不补则 WiFi 刀无法按「读盘验收」。  
> WiFi **协议本身**不依赖 Sdhost 写；这是**工程验收通道**。

### pi-sd-1 · Sdhost 单块写 <a id="pi-sd-1"></a>

|---|---|
| **做** | 实现 `SdhostWriteOneBlock`（CMD24）+ `SdhostWrite` 循环；PIO 写 `SDDATA`；写后 busy；对表本侧 `SdhostReadOneBlock` / Duo 的 **CMD24 语义**（**不要**抄 Duo SDHCI 寄存器） |
| **碰** | `Kernel/HAL/Arm64/Board/rpi-3b/Sdhost/**` 仅 |

## pi-wifi · BCM43430 <a id="pi-wifi"></a>

> **序**：对照对齐 → SRAM 同周期自证 → HT/ARM → 固件验 → SDPCM/scan → IP。  
> **一次只改一个变量**；每刀涨 `WIFI_BUILD_TAG`。  
> **禁止**：字节模式写 SRAM 当主实验（本仓注释 + brcmf 灌片为块模式）；跨上电比 SRAM；用 `csr=0x50` 当第一失败因。
>
> **本故事已完成的前半**（勿重做）：[归档 B](#archive-done) — pwifi-1、枚举/F1/FBR64/背板寄存器/EROM、刀 A+B（tag `0x124`）、Linux ftrace。  
> **下面从 pi-wifi-1 起才是未完成 PR。**

### Linux 对照摘要（写进各 PR 描述）

来源：`mmc-brcmf-trace.txt`（重载 `brcmfmac` 窗口）。

| 观察 | 数值 / 含义 |
|---|---|
| 主机 | **mmc1**（Arasan），非 mmc0 |
| ios | 50 MHz、4-bit、sd high-speed |
| CMD 统计（该次） | CMD52 ≫ CMD53；CMD53 ≈ 1610 次量级（含 start/done） |

| 方向 | `data_flags=0x100` 写 / `0x200` 读 |
| 芯片 | `SDIO_ID=02D0:A9A6`；`F1 signature @0x18000000=0x1541a9a6` |
| 固件串 | `brcm/brcmfmac43430-sdio` → `7.45.98 (TOB)` |
