## pi-wifi-7 · 关联后 IP（拆刀） <a id="pi-wifi-7"></a>

> **总判据**：ping 通网关或固定靶。  
> **协议**：仍 SDPCM / WLC_*；DATA 通道对表 cyw43 `DATA_HEADER`。  
> **一次一刀**；每刀涨 `WIFI_BUILD_TAG`；CH 读对应 `WIFI-*.LOG`。  
> **勿改** `Shell/Commands/Wifi.c`（Duo weak）；Pi 继续板包 Claim / 落盘。

### 已收 · pi-wifi-7a · WPA2 关联课网 <a id="pi-wifi-7a"></a>

| 项 | 内容 |
|---|---|
| **做** | 扫到 `Apple` → cyw43 序 `wsec`/`wsec_pmk`/`wpa_auth` + `SET_SSID`；等 LINK |
| **判据** | `WIFI-JOIN.LOG`：`status=join-ok` 且 `event_type=16` `event_status=0` |
| **进度** | ✅ TG+TS tag **`0x150`**（`d68e8bdc`） |

### 已收 · pi-wifi-7b · DATA 通道眼睛 <a id="pi-wifi-7b"></a>

| 项 | 内容 |
|---|---|
| **做** | join 后 `cur_etheraddr`（首 6B）+ 轮询 F2 DATA；通道计数落盘 |
| **判据** | `net-data-ok` + `data_pkts>0` + 非零 MAC |
| **进度** | ✅ tag **`0x152`**（待 TG）；`mac=b8:27:eb:17:66:ee` `data_pkts=1` `first_etype=2054`（ARP） |
| **0x151 否证** | 取响应末 6B → 全 0；cyw43 取首 6B |

### pi-wifi-7c · SDPCM ↔ lwIP（拆刀） <a id="pi-wifi-7c"></a>

> 总目标：二层收/发进 lwIP。Pi 已有 **SMSC 有线** 主网卡——WiFi 接入须显式 epoch/主网卡策略，**禁止**半截抢环饿鼠。

#### 已收 · pi-wifi-7c0 / 7c1 · 探针眼睛 + SDPCM TX <a id="pi-wifi-7c0"></a> <a id="pi-wifi-7c1"></a>

| 项 | 内容 |
|---|---|
| **7c0** | sram 失败 stage 细分进树；本轮灌片直通未踩红 |
| **7c1** | `send_ethernet` + who-has（眼靶 `172.20.10.1`） |
| **进度** | ✅ TG+TS tag **`0x155`**（`c46bc5c8`）：`net-tx-ok` |
| **0x153 否证** | 绑被动 ARP；**0x154**×2 卡 `load-sram-probe`（偶发） |

#### 已收 · pi-wifi-7c2 · DATA RX → LwIpNetif <a id="pi-wifi-7c2"></a>

| 项 | 内容 |
|---|---|
| **做** | DATA→`LwIpNetifInput`；DHCP Discover 引出帧 |
| **进度** | ✅ TG+TS tag **`0x15a`**（`d4e97e61`）：`net-lwip-in-ok` `lwip_in=3` |
| **否证** | ARP（含 SPA≠0）引不出 DATA；须 DHCP Discover |

#### 已收 · pi-wifi-7c3 · netif TX → SDPCM <a id="pi-wifi-7c3"></a>

| 项 | 内容 |
|---|---|
| **做** | `BoardWifiArmNetifLinkOutput` + `TryLinkOutput`；`PlatformSendEthernet` 优先 WiFi；Kick 前 `LwIpInitialize` |
| **判据** | `net-lwip-out-ok` 且 `lwip_out>0` |
| **进度** | ✅ TG+TS tag **`0x15c`** |
| **否证** | `0x15b`：Kick 时 lwIP 未起 → `out-arm-fail` |

### 已收 · pi-wifi-7d · DHCP <a id="pi-wifi-7d"></a>
