## Bug · 登记 <a id="bugs"></a>

### bug-nuc-idle-kbd · NUC 闲置后按键不灵 <a id="bug-nuc-idle-kbd"></a>

| 项 | 内容 |
|---|---|
| **板** | X64 NUC（桌面 + USB HID） |
| **现象** | 鼠标闲置约十余分钟后，**按键不灵**（用户 2026-11-02 记） |
| **根因（对表 xHCI）** | ① 真机 `HaltOnly` 不做 HCRST → UEFI 写的 **PORTPMSC** U1/U2/HLE 残留；鼠停后口可进低功耗，键报 Transaction Error。② 错误完成码使中断 EP **Halted** 后旧路径只 `QueueIntr` 敲门铃（4.6.8 忽略）→ 永久死。~10 min 来自固件/口策略，树内无该定时器。 |
| **改法** | `ClearFirmwarePortLinkPowerManagement`（启控后清 PORTPMSC + LWS 回 U0）；`CompletionCodeHaltsEndpoint` → `RecoverHaltedInterrupt`（Reset EP→Set TR Deq）再投；去掉 Drain 空闲门铃轻推。未改 400 ms/5 s 鼠优先门闩。 |
| **判据** | 启串口见 `XHCI port link PM cleared`；闲置 ≥15 min 后键仍灵；若曾 TE，串口可有 `kbd-intr cc=` 后键恢复 |
| **状态** | 🔧 代码收口；**待 NUC 闲置手测**（未 TG） |
