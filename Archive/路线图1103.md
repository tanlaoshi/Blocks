## 热更 · 冻结窗 / 校验 <a id="ksend-freeze"></a>

用户点名（2026-11-02）：串口热更时 NUC 鼠死；要「握手」感。

| 板 | 行为 |
|---|---|
| **NUC / Pi** | 检测到热更请求 → **冻结** Gui/输入；大窗（对表拔盘提示）「正在热更」；完成后关窗 |
| **Duo** | 串口一行「热更中」；热更期间不接壳输入 |
| **校验** | 现协议已是 **块 CRC32 + 整文件 CRC**（`KsendFileVerify`）；**不必另上 MD5**（同强度用途，免双算）。对外可称「校验和」，勿误写成未实现的 MD5 |

## 热更 · 回退（设计答，未开刀） <a id="ksend-rollback"></a>

> **问**：Worker 监控「新核挂了就回退」能否做？启动期就挂怎么办？

| 点 | 结论 |
|---|---|
| **Worker 不够** | Worker 活在**当前** Kernel 里；新核若在入口/页表/驱动早期挂掉，Worker **根本起不来**，无法自救。 |
| **要 BootStub / 引导计数** | 对表现 Duo BootStub：Stub 常驻 → 加载 `BLOCKS:Kernel.elf`；加 **boot-counter / 试跑旗**：Stub 置「试跑中」→ 跳新核 → 新核用户态/壳活后清旗；若计数超限或旗未清 → Stub **改载 `.bak` / 上一槽**。 |
| **A/B 槽** | 可选双文件 `Kernel.elf` / `Kernel.prev.elf`（或 slot A/B）；ksend 写非运行槽，Stub 切槽；比单文件 `.bak` 更清晰。 |
| **现状** | ksend 已写 `Kernel.elf.bak`；**缺 Stub 侧「失败自动切回」**。X64/Pi 若无对等 Stub，需各板引导路径补同形策略。 |
| **排期** | `ksend-rollback` P2；**点名再开**（不塞进本 ★） |

## 热更 · 网络主路（决策） <a id="net-ksend"></a>

> **决策（2026-11-02）**：目标仍是 **日常热更走网络**；串口降备份。  
> **真机口径（2026-11-02 22:40 用户纠正）**：**差很多**——不能把「门面/单板绿」写成三板齐。

| 板 | 网络 TCP ksend | 备注 |
|---|---|---|
| **NUC** | ✅ **有线**；✅ **Wi‑Fi**（2026-11-03） | `ip`→`ksend serve`→`--host`→`KSEND OK`。根因：iwl `Len>400` 拒 MSS 段；串口热更勿把载荷 `0x03` 当 Ctrl-C；批写 64KiB 免 ACK 被 FAT 拖死 |
| **Pi** | ❌ TCP 写块 `FAIL reason=header` | `info`/握手尚可；插网线后仍 `via wifi`；串口小差量≠网热更绿 |
| **Duo** | ✅ **有线**；✅ **Wi‑Fi**（2026-11-03 双栈） | `HalNetWifiAdoptLease` 后 `ip via wifi`；`ksend serve`→`--host`→`KSEND OK`。RSN 组播须 CCMP |

| 层 | 做法 |
|---|---|
| **协议** | 复用现有 ksend 帧（差量 4K / CRC / path / reboot）；**不**另起 OTA |
| **传输** | 主：TCP（板 listen，PC `ksend.py --host`）；备：现串口 `HalSerial*` |
| **写盘** | 路径不变：X64 `BLOCKS:Kernel.elf`（U 盘）；Duo `BLOCKS:Kernel.elf`；Pi 同形 |
| **发现** | 先固定 IP / `who` 对表；mDNS/广播后排 |
| **首刀** | `net-ksend-1`：传输抽象（serial\|tcp）+ `ksend serve` + PC `--host` + 壳 **`ip`** |
| **有线/Wi‑Fi** | listen `INADDR_ANY`；址取 NetConfig 主口（`ip` 打 `via wired`/`via wifi`） |
| **默认端口** | **26992** |
| **收口判据** | **三板**均可 `ip`→`serve`→PC `--host`→`KSEND OK`（有线优先；Wi‑Fi 另证）。仅 NUC ≠ 收官 |

**手测**：板上 `ip` → `ksend serve`；PC `ksend.py --host <ip> --file …`。写前可 `who`。
