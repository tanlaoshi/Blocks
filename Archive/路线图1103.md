### 现场标记 · Pi Wi‑Fi 热传（⏸ 暂缓，代码已 TG） <a id="pi-wifi-ksend-wip"></a>

| 项 | 内容 |
|---|---|
| **现象** | USB1 自测：`ip via wifi` + READY/CRC 表 OK → 首块 **`KSEND FAIL reason=header err=1`**（读头超时） |
| **否证** | `0x15f` feed 节流；`0x160` credit-wait 喂 DATA；`0x161` TX 期 defer RX —— **仍 err=1**（`DeferPop` 仍在 `tcp_output` 栈内 flush → 重入） |
| **未测刀** | **`WIFI_BUILD_TAG=0x162`**：defer **只入队**；`PollFeed` 且 defer depth==0 再 flush（出 `tcp_output`）。卡已 CK（2026-11-03 18:25）；**Wi‑Fi 路径未复测** |
| **处置** | 用户插网线 → **先收 Pi 有线**；Wi‑Fi 点名再开，续 `0x162` 或新证据，勿丢现场补丁 |

## 热更 · 网络主路（决策） <a id="net-ksend"></a>

> **决策（2026-11-02）**：日常热更走网络；串口降备份。  
> **真机口径**：**一门面≠三板收官**。

| 板 | 网络 TCP | 备注 |
|---|---|---|
| **NUC** | ✅ 有线；✅ Wi‑Fi | `ip`→`serve`→`--host`→`KSEND OK` |
| **Duo** | ✅ 有线；✅ Wi‑Fi（双栈） | `HalNetWifiAdoptLease`→`ip via wifi` |
| **Pi** | ✅ 有线；Wi‑Fi ⏸ | `192.168.31.168 via wired`→`KSEND OK`（2026-11-03 USB1）；Wi‑Fi 见 [现场](#pi-wifi-ksend-wip) |

| 层 | 做法 |
|---|---|
| **协议** | 复用现帧（差量 4K / CRC / path / reboot）；**不**另起 OTA |
| **传输** | 主：TCP（板 listen，PC `--host`）；备：串口 |
| **写盘** | X64 `BLOCKS:Kernel.elf`（U 盘）；Duo/Pi 同形；Pi Wi‑Fi 主槽批写=每块 |
| **默认端口** | **26992** |
| **收口判据** | 三板有线/主路 TCP 齐；**Pi Wi‑Fi 另点名** |
| **Pi 契约** | `HalNetWifiShouldOwnTransmit`；Adopt 拒插线；探网插线 skip |

**手测**：板上 `ip` → `ksend serve`；PC `--host <ip>`。Pi Wi‑Fi：拔线冷启，点名再开。
