### 刀说明 · 存储边角

| 项 | 一句话 | 手测 |
|---|---|---|
| **NVMe 多 NS** | 现写死 NSID=1；Identify 列 NS → 各映 Block drive；挂载环复用 | QEMU 多 NS / 企业盘 |
| **NVMe MSI** | 现同步轮询、CQ `IEN=0`；接 PCI MSI + 完成路径（可留 poll 备份） | QEMU / NUC |

| 项（已收 / 跳过） | 一句话 | 手测 |
|---|---|---|
| **NVMe 4K LBA** | 驱动内 512e（LBADS>9）；非整块写 RMW；GPT/FAT 不动 | QEMU `DISK=nvme4k` ✅（LBADS=c）；`DISK=nvme` 回归 ✅ |
| **多盘多卷** | `BLOCKS:`/DB→OsTarget；GUID 缓存清；Block Fan 并存 AHCI+NVMe；去内置压 MSC | NUC ✅（U 盘起 + SSD） |
| **psmp-3a** | BCM2836/7 **本地中断控制器**接每核 CNTV；`HalTimerUsesIrq` 真机可 1 | 3B **CK** ✅ |
| **psmp-3b** | （跳过）钉核同 NUC / HID | — |
| **`.so` TLS/COPY** | `R_*_COPY` + 主 ELF `PT_TLS` | QEMU `dyndemo` ✅ |

> **序**：多盘多卷 ✅ → 4K LBA ✅ → **多 NS** → MSI。未点 ★ 不开下一刀。手机活见 [`路线图1107.md`](路线图1107.md)。
