# 编码规范（指针）

> **正本在 [`../../Archive/规范/编码规范.md`](../../Archive/规范/编码规范.md)。** 本文不再单独维护。

一句话记住四条：

1. **写全名**，尽量不用缩写（`Cfg`→`Config`、`Addr`→`Address`）；
2. **命名照 EDK2**：PascalCase、名词在前动词在后、全局 `gXxx`、文件内静态 `sXxx`；
3. **函数 ≤60 行、文件 ≤300 行**，超了先拆再写；
4. **不用魔法数**：寄存器偏移、超时、尺寸一律起名并写出处。

细则（分层、注释、C99 方言、与 EDK2 的对照表、简写黑白名单）全在正本。
