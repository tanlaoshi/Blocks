# 如何写一个分配器

> **产品名 Blocks**。默认政策 **bitmap**（first-fit）；学生模板 **best-fit**，默认不链进内核。

| 角色 | 路径 |
| --- | --- |
| 默认政策 | `Core/PhysicalMemory/Bitmap.c` |
| 学生模板 | `Core/PhysicalMemory/Student/BestFit.c` |
| 政策表 | `Include/Core/MemoryOps.h` → `MEMORY_OPS` |
| 段访问 | `PmmSegment` / `PmmLookup`（勿直接碰 `gSegments`） |

## 你要改的函数

`MEMORY_OPS` 里真正属于政策的是：

| 函数 | 做什么 |
| ---- | ------ |
| `Init` | 清自己的状态。不要初始化锁或段表。 |
| `AllocPagesLocked` | 在段内找空闲连续页并置位；`Count==0` 或不够则返回 NULL。 |
| `FreePagesLocked` | 降引用或清位；页不在段内则警告。 |
| `RetainPageLocked` / `ReleasePageLocked` | COW 引用计数；饱和 / 未分配返回 -1。 |

调用时框架已经拿着 `gPhysLock`，函数里不要再加锁。

本模板与默认的差别在 **找空闲**：默认 first-fit（从前往后第一个够长的空洞）；模板 best-fit（在够长的空洞里选最短的）。实现上常改模板内的 `SegmentFindFreeRange` 一类辅助，再接到 `AllocPagesLocked`。

## 怎么编译和测试

```bash
cd ~/Blocks/Kernel
make runtests-memory
make MEMORY=bestfit runtests-memory   # 断言学生模板
make MEMORY=bestfit                   # 链进内核后再 build
```

默认 `./build.sh` / `build` 仍是 `MEMORY=bitmap`。

`make MEMORY=nosuch` 会报错，避免把未知目录扫进内核。
