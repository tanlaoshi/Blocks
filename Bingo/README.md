# Bingo — 从这里动手

> 无论写 App、驱动、读源码、贡献还是上课：**入口都在本目录**。  
> 排期 / 日档 / 过程归档仍在 [`Archive/`](../Archive/README.md)，不进本树。

## 你是谁 → 去哪

| 身份 | 入口 | 一句话 |
| ---- | ---- | ------ |
| **A** 写 App | [`App/`](App/README.md) | 毛坯 · 样例 · ELF / UI / 网 / 商店 |
| **B** 写驱动 | [`Driver/`](Driver/README.md) | Probe / Bind / 匹配 / 模板 |
| **C** 读源码做研究 | [`System/`](System/README.md) | 字典、开机、目录树、syscall 真源 |
| **D** 参与贡献 | [`Contribute/`](Contribute/README.md) | 接手、编码规范、改 ABI 同步清单 |
| **E** 学生 / 作业 | [`Course/`](Course/README.md) | 速查卡、冻结面、课堂作业 |

共用五分钟上机：[`BINGO.md`](BINGO.md)。

| 树 | 管什么 |

| [`Archive/原则与学习记录.md`](../Archive/原则与学习记录.md) | 从 OVMF 逐段 review 的长叙事（System 入口会链到） |
