# Documents — 文档地图

> 从 ToyKernel 同步后已按用途重排。根目录 [原则与学习记录.md](../原则与学习记录.md) 是 Blocks 从 OVMF 逐段 review 的活白皮书，**不进本树**。

## 谁读什么

| 你要… | 去哪 |
| ------ | ---- |
| 看排期 / ★ 当前刀 | [项目/路线图.md](项目/路线图.md) 文首；日常记 [项目/进展/](项目/进展/) |
| 看分层与架构 | [项目/技术手册.md](项目/技术手册.md) |
| 写代码守什么规矩 | [规范/代码规范.md](规范/代码规范.md)（短；细则在备查） |
| 开课后自学改内核/应用 | [手册/开发者接手指南.md](手册/开发者接手指南.md) |
| 写用户态 App | [手册/应用开发指南.md](手册/应用开发指南.md) + [API速查](手册/API速查.md) |
| 写驱动 | [手册/驱动/驱动开发指南.md](手册/驱动/驱动开发指南.md) |
| 查拆分/排障/柱史 | [过程/](过程/)（历史；ABI 号可能旧） |
| 未收官柱规格 | [柱规格/](柱规格/) |

**用户 ABI**只认 [手册/开课ABI冻结.md](手册/开课ABI冻结.md) + `Kernel/CodeE-User/include/` 宏。  
改接口同步顺序：头文件 → 开课ABI冻结 → 学生速查卡 → API速查 → 应用开发指南 →（必要时）技术手册 §IV。
