## 1 · c99-dialect · C99 方言收拢 <a id="c99-dialect"></a>

> **目标**：**Kernel 自有树**在 **`-std=c99`** 下编过；业务不写 C11、不散落 GNU。  
> **自有树（收拢范围）**：`Kernel/{Core,Services,HAL自研,BringUp,Library,Include,User,OpenBox}`。  
> **例外（不收拢）**：`Boot/BootPkg`（跟 EDK2）、`Boot/EDK2`、`ThirdParty/`、**lwIP**。  
> **估时**：约数天（5 小刀）；无 ABI/产品行为变更，风险低。  
> **允许垫片**（仍算锚定 C99）：① `stdarg.h` 的 `__builtin_va_*`；② `Compiler.h` 属性/断言；③ `Atomic.h` 的 `__sync_*` 展开。  
> **保留的 C99**：`for (int`、指定初始化、`long long`、`inline`、带名联合 `.U.Pci` 等。  
> **不要**（仅 Kernel 业务）：`_Static_assert`、手写 `__attribute__`/`__builtin_*`、`-std=gnu99`。

| 刀 | 一句 | 主战场 | 风险 / 验收 | 状态 |
| --- | --- | --- | --- | --- |
| **[c99-1](#c99-1) · 垫片+锁标** | 新建 `Compiler.h`；CFLAGS 加 `-std=c99`；先能编过（告警可后收） | `Include/` 或 `Abi/`、`Makefile`、`BlocksUser.mk` | 低；`./build.sh` 过 | ✅ |
| **[c99-2](#c99-2) · 断言** | `_Static_assert`→`BLOCKS_STATIC_ASSERT`；`BLOCKS_OFFSETOF` | Kernel：BringUp 配置头、Abi、Ramfb、Syscall（Boot 不改） | 低；布局断言仍在编译期炸 | ✅ |
| **[c99-3](#c99-3) · 属性收宏** | Kernel 自有 `__attribute__` 改宏；业务零手写 attribute | HAL/驱动/协议结构、~40 文件 | 中；MMIO/打包结构勿改布局 | ✅ |
| **[c99-4](#c99-4) · builtin 清扫** | `unreachable`/`bswap`/STB 的 builtin→自写或 CRT | Ramfb、TrueTypeRaster 等（Boot 除外） | 低 | ✅ |
| **[c99-5](#c99-5) · pedantic 收口** | Kernel 加 `-pedantic`；`rg` 门禁空；Boot/ThirdParty 保持原 flags | Makefile、短说明进 [规范/代码规范.md](规范/代码规范.md) | 低；全量 build 过 | ✅ |
| **[c99-atomic](#c99-atomic) · sync 垫片** | `__sync_*`→`Atomic.h`；不引入 C11 stdatomic | SpinLock、串口、MSC、调度计数等 | 中；SMP 语义勿改 | ✅ |

#### c99-1 · 垫片+锁标 <a id="c99-1"></a>

✅ TG+TS。

- `Kernel/Include/Abi/Compiler.h`：`BLOCKS_PACKED` / `ALIGNED(n)` / `NORETERN` / `MS_ABI`  
- `CFLAGS_BASE` + 两处 `USER_CFLAGS` + `BlocksUser.mk`：`-std=c99`  
- `User/include/stdarg.h` 注明垫片  
- `./build.sh`（x86_64 virt，LWIP=1）通过  
- **例外**：`CFLAGS_FT`、`ThirdParty/lwip` 末尾 `-std=gnu11`

#### c99-2 · 断言 <a id="c99-2"></a>

✅ TG+TS。`BLOCKS_STATIC_ASSERT` / `BLOCKS_OFFSETOF` 进 `Compiler.h`；**Kernel** 自有 `_Static_assert` 已清。`UefiBootConfig` 内核副本用垫片；**Boot 副本保持 EDK2 `_Static_assert`**（方言不收 Boot）。`BlocksUser.mk` 补 `-IInclude/Abi`。

#### c99-3 · 属性收宏 <a id="c99-3"></a>

✅ TG+TS。`Compiler.h` 补 `BLOCKS_SECTION` / `USED`；Kernel 自有 `__attribute__` → 垫片宏。顺带：Boot 按 PT_LOAD 装载、大 BSS 上抬、`SchedulerStart` 保持 cli 至 Enter（修 CI smoke）；Boot 断言回 EDK2 风格。

#### c99-4 · builtin 清扫 <a id="c99-4"></a>

✅ TG+TS。Kernel `rg '__builtin_'` 仅剩：`stdarg.h`、`Compiler.h`。不扫 Boot。

- `Ramfb.c`：自写 `Bswap32`（去 `bswap32` builtin）
- `TrueTypeRaster.c`：`STBTT_strlen/memcpy/memset` → CRT
- `UefiBootConfig.h`（Kernel）：`BLOCKS_OFFSETOF`（已含 `Compiler.h`）
- `./build.sh`（x86_64 virt，LWIP=1）通过
- **未动**：`__sync_*`（本刀外）；Boot 保持 EDK2

#### c99-5 · pedantic 收口 <a id="c99-5"></a>

✅ TG+TS。Kernel `CFLAGS_BASE` / `USER_CFLAGS` / `BlocksUser.mk` 加 `-pedantic`；[规范/代码规范.md](规范/代码规范.md) §7 记方言与 `rg` 门禁。

- `ArchIdtSetGate` 改 `UINTN`（去函数指针↔`void *` pedantic）
- lwIP `cc.h`：`LWIP_NO_STDINT_H`；上游 `.o` 加 `-Wno-pedantic`
- `./build.sh` 过且 **零** `[-Wpedantic]`
- 两道 `rg` 业务空（仅垫片文件）
#### c99-atomic · `__sync_*` 垫片 <a id="c99-atomic"></a>

✅ TG+TS。`Include/Abi/Atomic.h`：`BLOCKS_ATOMIC_{TAS,RELEASE,FETCH_ADD,CAS,FENCE}`。

- 业务清扫：SpinLock / pthread / Gui 拖帧 / LwIp soft / Serial / XHCI MSC / Virtio fence / 调度计数
- `rg '__sync_'` 仅剩 `Atomic.h`；`./build.sh` 过
- 规范 §7 补第三道门禁；**不**上 C11 `<stdatomic.h>`

**整柱验收**：

- [x] Kernel `-std=c99` 编过  
- [x] Kernel 无 C11 关键字；无业务 GNU 散落  
- [x] 垫片仅 `Compiler.h` + `Atomic.h` + `stdarg.h`  
- [x] Boot / ThirdParty / lwIP / EDK2 例外有记录

## 2 · sdk-pack · 离树 BlocksSDK <a id="sdk-pack"></a>

> **目标**：维护者一条命令打出 **`Build/BlocksSDK.tar.gz`**；学生/课外解压后**无需 Kernel 树**即可 `make` 出静态 ELF。  
> **范围**：x86_64 预编译 CRT/库 + 头 + `BlocksSdk.mk` + Hello/Gui/Net 示例。  
> **不做**：Arm/RiscV 包、Guest 内编译、完整示例集回灌。

| 刀 | 一句 | 主战场 | 风险 / 验收 | 状态 |
| --- | --- | --- | --- | --- |
| **[sdk-1](#sdk-1) · 复活 build-sdk** | 脚本+Sdk 树；离树 Hello/Gui/Net `make` | `Tools/build-sdk.sh`、`Tools/Sdk/` | 低；`/tmp` 解压验收 | ✅ |

#### sdk-1 · 复活 build-sdk <a id="sdk-1"></a>

✅ TG+TS。

- `Tools/build-sdk.sh` → `Build/BlocksSDK/` + `.tar.gz`（`VERSION=1.0.0-course`）
- `Tools/Sdk/`：`BlocksSdk.mk`、模板、Examples/{Hello,Gui,Net}
- `Blocks/syscall.h` → `#include <Abi/SyscallABI.h>`（树内/包内同路径）
- `./build.sh sdk` 转调打包；指南 / Package README 对齐 Blocks 名
- 附带：CRT `printf` 整段 write；用户 stdout 免 PresentFlush；x64 `HalUserCoopEnter` + 无窗 ELF CoopDrain
- **验收**：`tar xzf` 到 `/tmp` 后三例 `make` 出静态 ELF（入口在 `0x40000000` 段）；`run user` 回 `blocks>`
