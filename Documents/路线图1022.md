## 1 · c99-dialect · C99 方言收拢 <a id="c99-dialect"></a>

> **目标**：**自有树**在 **`-std=c99`** 下编过；业务不写 C11、不散落 GNU。  
> **自有树**：`Kernel/{Core,Services,HAL自研,BringUp,Library,Include,User,OpenBox}` · `Boot/BootPkg`。  
> **例外（不收拢、可保留原 flags）**：`ThirdParty/`、`Boot/EDK2`、**lwIP**（约十万行级，与自有代码同量级——只链、不改方言）。其它嵌入上游同此。  
> **估时**：约数天（5 小刀）；无 ABI/产品行为变更，风险低。  
> **允许垫片**（仍算锚定 C99）：① `stdarg.h` 的 `__builtin_va_*`；② `BLOCKS_PACKED` / `BLOCKS_ALIGNED(n)` 等仅在 **唯一** `Compiler.h` 展开。  
> **保留的 C99**：`for (int`、指定初始化、`long long`、`inline`、带名联合 `.U.Pci` 等。  
> **不要**：`_Static_assert`、业务里 `__attribute__`/`__builtin_*`、`-std=gnu99`。

| 刀 | 一句 | 主战场 | 风险 / 验收 | 状态 |
| --- | --- | --- | --- | --- |
| **[c99-1](#c99-1) · 垫片+锁标** | 新建 `Compiler.h`；CFLAGS 加 `-std=c99`；先能编过（告警可后收） | `Include/` 或 `Abi/`、`Makefile`、`BlocksUser.mk` | 低；`./build.sh` 过 | ✅ |

#### c99-1 · 垫片+锁标 <a id="c99-1"></a>

✅ TG+TS。

- `Kernel/Include/Abi/Compiler.h`：`BLOCKS_PACKED` / `ALIGNED(n)` / `NORETERN` / `MS_ABI`  
- `CFLAGS_BASE` + 两处 `USER_CFLAGS` + `BlocksUser.mk`：`-std=c99`  
- `User/include/stdarg.h` 注明垫片  
- `./build.sh`（x86_64 virt，LWIP=1）通过  
- **例外**：`CFLAGS_FT`、`ThirdParty/lwip` 末尾 `-std=gnu11`

#### c99-2 · 断言 <a id="c99-2"></a>

✅ TG+TS。`BLOCKS_STATIC_ASSERT` / `BLOCKS_OFFSETOF` 进 `Compiler.h`；自有 `_Static_assert` / `__builtin_offsetof` 已清（EDK2 例外）。双份 `UefiBootConfig.h` 就地同口径宏（不 #include 内核）。`BlocksUser.mk` 补 `-IInclude/Abi`。验收：`./build.sh` 过；故意 `sizeof` 错 → 编译失败。

#### c99-3 · 属性收宏 <a id="c99-3"></a>

★。`rg '__attribute__'` 自有树（排除 `Compiler.h`）→ 空。只换拼写/宏，**不改**成员顺序与尺寸。验收：关键打包结构 `sizeof` 与改前一致（Ramfb/BootConfig/驱动描述符抽测）。

#### c99-4 · builtin 清扫 <a id="c99-4"></a>

排队。自有树 `rg '__builtin_'` 仅允许：`stdarg.h`、`Compiler.h`（若有）。其余改普通 C。验收：同上 rg 门禁。

#### c99-5 · pedantic 收口 <a id="c99-5"></a>

排队。自有目标加 `-pedantic`（或 `-Wpedantic`）修剩警告；文档一句写入 [规范/代码规范.md](规范/代码规范.md)（语言=C99+垫片）。整柱验收：`build` 过 + 两道 `rg` 空。TG 后 ★ 空或开下一柱。

**整柱验收**：

- [ ] 自有代码 `-std=c99` 编过  
- [ ] 无 C11 关键字；无业务 GNU 散落  
- [ ] 垫片仅 `Compiler.h` + `stdarg.h`  
- [ ] ThirdParty / lwIP / EDK2 例外有记录
