## 1 · c99-dialect · C99 方言收拢 <a id="c99-dialect"></a>

> **目标**：**Kernel 自有树**在 **`-std=c99`** 下编过；业务不写 C11、不散落 GNU。  
> **自有树（收拢范围）**：`Kernel/{Core,Services,HAL自研,BringUp,Library,Include,User,OpenBox}`。  
> **例外（不收拢）**：`Boot/BootPkg`（跟 EDK2）、`Boot/EDK2`、`ThirdParty/`、**lwIP**。  
> **估时**：约数天（5 小刀）；无 ABI/产品行为变更，风险低。  
> **允许垫片**（仍算锚定 C99）：① `stdarg.h` 的 `__builtin_va_*`；② `BLOCKS_PACKED` / `BLOCKS_ALIGNED(n)` 等仅在 **唯一** `Compiler.h` 展开。  
> **保留的 C99**：`for (int`、指定初始化、`long long`、`inline`、带名联合 `.U.Pci` 等。  
> **不要**（仅 Kernel 业务）：`_Static_assert`、手写 `__attribute__`/`__builtin_*`、`-std=gnu99`。

#### c99-1 · 垫片+锁标 <a id="c99-1"></a>

✅ TG+TS。

- `Kernel/Include/Abi/Compiler.h`：`BLOCKS_PACKED` / `ALIGNED(n)` / `NORETERN` / `MS_ABI`  
- `CFLAGS_BASE` + 两处 `USER_CFLAGS` + `BlocksUser.mk`：`-std=c99`  
- `User/include/stdarg.h` 注明垫片  
- `./build.sh`（x86_64 virt，LWIP=1）通过  
- **例外**：`CFLAGS_FT`、`ThirdParty/lwip` 末尾 `-std=gnu11`

#### c99-2 · 断言 <a id="c99-2"></a>

✅ TG+TS。`BLOCKS_STATIC_ASSERT` / `BLOCKS_OFFSETOF` 进 `Compiler.h`；**Kernel** 自有 `_Static_assert` 已清。`UefiBootConfig` 内核副本用垫片；**Boot 副本保持 EDK2 `_Static_assert`**（方言不收 Boot）。`BlocksUser.mk` 补 `-IInclude/Abi`。

#### c99-3 · 属性收宏 <a id="c99-3"></a>

✅ TG+TS。`Compiler.h` 补 `BLOCKS_SECTION` / `USED`；Kernel 自有 `__attribute__` → 垫片宏。顺带：Boot 按 PT_LOAD 装载、大 BSS 上抬、`SchedulerStart` 保持 cli 至 Enter（修 CI smoke）；Boot 断言回 EDK2 风格。

#### c99-4 · builtin 清扫 <a id="c99-4"></a>

✅ TG+TS。Kernel `rg '__builtin_'` 仅剩：`stdarg.h`、`Compiler.h`。不扫 Boot。

- `Ramfb.c`：自写 `Bswap32`（去 `bswap32` builtin）
- `TrueTypeRaster.c`：`STBTT_strlen/memcpy/memset` → CRT
- `UefiBootConfig.h`（Kernel）：`BLOCKS_OFFSETOF`（已含 `Compiler.h`）
- `./build.sh`（x86_64 virt，LWIP=1）通过
- **未动**：`__sync_*`（本刀外）；Boot 保持 EDK2

#### c99-5 · pedantic 收口 <a id="c99-5"></a>

✅ TG+TS。Kernel `CFLAGS_BASE` / `USER_CFLAGS` / `BlocksUser.mk` 加 `-pedantic`；[规范/代码规范.md](规范/代码规范.md) §7 记方言与 `rg` 门禁。

- `ArchIdtSetGate` 改 `UINTN`（去函数指针↔`void *` pedantic）
- lwIP `cc.h`：`LWIP_NO_STDINT_H`；上游 `.o` 加 `-Wno-pedantic`
- `./build.sh` 过且 **零** `[-Wpedantic]`
- 两道 `rg` 业务空（仅垫片文件）
- **仍散落（本柱外）**：业务 `__sync_*`（可另开 `c99-atomic` 垫片收）

**整柱验收**：

- [x] Kernel `-std=c99` 编过  
- [x] Kernel 无 C11 关键字；无业务 GNU 散落（`__sync_*` 另计）  
- [x] 垫片仅 `Compiler.h` + `stdarg.h`  
- [x] Boot / ThirdParty / lwIP / EDK2 例外有记录
