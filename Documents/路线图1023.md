## 1 · rpi-desk · 树莓派 3B+（公司 QEMU / 回家 SD） <a id="rpi-desk"></a>

> **目标**：把 **Arm64 桌面真机靶**钉在 **Raspberry Pi 3B+**；开发节奏拆成「公司能推进」与「回家必须验」。  
> **启动链**：厂商/社区 **U-Boot + DTB**（`booti` 一类），**不是** UEFI SystemReady。  
> **对照**：板包约定 [`Kernel/HAL/Board/README.md`](../Kernel/HAL/Board/README.md)；QEMU 课堂靶仍是 `BOARD=virt`（[`run-virt-arm`](../Kernel/OpenBox/Scripts/run/run-virt-arm.sh)）。  
> **不做（本柱）**：Pixel 手机当靶；全志当主线；在无规格下堆 HDMI/USB「碰运气」；改厂商 U-Boot 源码。  
> **后置（不进本档刀表）**：HDMI FB、板载 USB 键鼠、有线/无线网——另开日档柱。

### 双机怎么测（总表）

| 场景 | 怎么测 | 说明 |
| ---- | ---- | ---- |
| **公司（无 3B+）** | `source env.sh` → `build arm64`（默认 virt）→ `run-virt-arm --headless` | 推 arch、板包**能编**、脚本、文档；与 BCM 无关的公共层 |
| **公司（无 3B+）** | `build arm64 BOARD=Raspberry/Pi3BPlus LWIP=0` | **只验编过 / 链接**；不假装真机过了 |
| **回家（有 3B+）** | 脚本产物写 **SD** → 上电（USB-TTL 串口优先） | 验 U-Boot 链、UART、DTB/memory |
| **Pixel 等** | 不当移植靶 | 启动链/闭源外设对不上「先查标准」 |

流程：

1. 公司：`TB` → 改 ★ 刀 → virt 与/或 `BOARD=Raspberry/Pi3BPlus` 编过 →（验后）`TG`；给家里再 `TS`。  
2. JX 收口若动板级：**写明须 3B+ SD 手测**。  
3. 回家：`TB` → 刷 SD → 串口日志；红了按规格改，公司勿堆超时/skip 启发式。

**Kernel 不是「只能写 SD」**——SD 是 **3B+ 真机验收**；公司主路径是 **交叉编译 + QEMU virt**（xPack 见 [同步.md](同步.md)「Tools」）。
