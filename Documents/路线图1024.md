## 0 · rpi-desk · 3B+ → 图形桌面 <a id="rpi-desk"></a>

> **承接**：[1023 rpi-0…3](路线图1023.md#rpi-desk)（板包 / SD / 串口壳 **✅**）。1023 曾把 HDMI/USB 标「后置」——本档接棒拆 PR。  
> **今晚 Definition of Done**：**HDMI 上看到 Blocks 桌面**（墙纸/图标级即可）。串口仍可进 `blocks>`。键鼠 **不**挡今晚过关（归 rpi-7）。  
> **不做混进一刀**：改厂商 U-Boot 源码；无规格猜分辨率；为「快点出画」关串口/饿死日后 HID。  
> **依赖事实（代码现状）**：
>
> | 已有 | 缺 |
> | --- | --- |
> | mini-UART；`boot.scr`；mbox/`memory` → Regions；mailbox FB；屏上滚；HDMI 桌面 | DWC2 HID；EL1；真 MMU；自动 bootcmd |
> | SD：`bootfs` + `BLOCKS`（宿主已摆；板侧块设备驱动仍缺则只 RES） | SDHOST/MSC 认 `BLOCKS.ID` |

### 今晚推荐顺序（单变量）

```text
rpi-4（memory 核对）→ rpi-5（mailbox 出像素）→ rpi-6（Gui 上屏）
         ↘ 若 5/6 被 EL/cache 卡住，再插 rpi-8 / rpi-9（勿一上来开 MMU）
rpi-7（键鼠）可并行调研，不挡「先见画」
rpi-10 最后抛光
```

#### rpi-7 · USB HID（键鼠） <a id="rpi-7"></a>

✅（2026-10-25 真机：鼠+键）。排障正本：[Pi3BPlus-DWC2-HID排障历程](过程/排障/Pi3BPlus-DWC2-HID排障历程.md)。

- [x] 基址 `0x3F980000`；`BoardDwc2Probe`：GSNPSID + soft-reset + force host + HPRT 上电  
- [x] 根口 reset（U-Boot 同形 60ms）→ 读 HPRT 速度（HS/FS/LS）  
- [x] ch0 DMA 控制传输；根口 hub `GET_DESCRIPTOR` + `SET_ADDRESS`  
- [x] HCDMA 用 `phys|0xC0000000`（手测曾 vid/pid=0 + SET_ADDR STALL＝未走总线别名）  
- [x] hub `SET_CFG` + class DESC → 各口 power → `st=` / 有设备则 reset → HS|FS|LS  
- [x] 真机：`vid=0424 pid=9514`（LAN9514）；`hub+5 FS`（外接键鼠口）  
- [x] SPLIT：`XACTPOS=ALL`；FS ep0 首包 MPS=8→18（曾 getdesc18 fail / HCINT 0x82）  
- [x] HID boot mouse 枚举（跳过 hub 上 HS 网口）；`046d:c09d` 真机过  
- [x] `DriverInputAttach` 鼠；Poll=中断 IN（NAK 空转）；键 Dequeue 可 NULL（后置）  
- [x] 早 Reveal（无 timer IRQ）+ `PresentCursor`→`FbDcacheSync`（鼠亮无箭头＝光标困 D-cache）  
- [x] 手测鼠：流畅 + 图标可双击开（2026-10-25）  
- [x] **键盘 HID**：hub+3 LS CASUE；GET18 失败仍 GET_CFG；cfg 按 8 递增 + ClearTT；不够则 **boot-fallback ep1**；真机可打字  
- [ ] 未露光标：勿狂泵鼠抢环（复查 Worker/HotPoll；不挡过关）  
- 对照：NUC xHCI 只作形状；**寄存器以 DWC2/BCM + U-Boot 为准**（勿 EDK2 主参考）  
- 易混：底边白块 = HOLD 缺字豆腐，**不是**光标

## 1 · selfhost · 自举与本位 <a id="selfhost"></a>

**不是**：Linux 兼容层、假 POSIX、为眼熟挂别名。  
原则短文：[`Manual/App/README.md` §0.1](../Manual/App/README.md)。

### 彻底还清 = 终态

1. **ISO C 标准库**（本仓 `libBlocks`）  
2. **Blocks 本位 API**（`Net*` / `Ui*` / `Graphics*` / `File*` / `Process*` / `Thread*`…）

| 终态要消失 | 终态可保留 |
| --- | --- |
| `sys/socket.h` POSIX 轨、`sockaddr`/`htons`、双轨文档 | `Net.h` / `libNet` |
| 公开导出的 `toy_*` | 内核内部随便叫（勿进 App 头） |
| 非 ISO C 的 `open`/`fork`/`opendir`/`pthread_*` 眼熟名 | `printf`/`malloc`/`fopen`/`strlen`… |
| 指南写「兼容 POSIX/Linux」 | 「Blocks App 这样写」 |

**不做的「假彻底」**：对齐 Linux 号表、上 musl、一夜删光导致 Chat 全红。

### 还债顺序

```text
叙事(sh-2) → 砍选修轨(sh-3) → 本位改名(sh-4) → libc 缺口(sh-5) → 自举(sh-6)
```

#### sh-1′ · main 钉原则 <a id="sh-1"></a>

✅。身份写入 App README；本柱立起；活 ★ 指针 → 本文件。

#### sh-2 · 叙事去脸 <a id="sh-2"></a>

✅。App/Course Manual 主路径只教 Blocks API。

#### sh-3 · 去别名与选修轨 <a id="sh-3"></a>

✅。POSIX `connect(sockaddr)` 轨停用；公开 `toy_*` 包装删除；Demo 改 `Net*`。

#### sh-4 · 本位 API <a id="sh-4"></a>

✅。`File*` / `Dir*` / `Process*` / `Thread*` / GUI 出 `unistd`；syscall 号不变。

#### sh-5 · libc 加厚缺口表 <a id="sh-5"></a>

✅。见 [`Manual/App/LibcGaps.md`](../Manual/App/LibcGaps.md)。

#### sh-sys · SYS_* 本位改名 <a id="sh-sys"></a>

✅。`SyscallABI.h` 去「POSIX 子段」叙事；宏名对齐 File/Process/Thread/Net/Window；**数值与段边界冻结**。Kernel + Chat/主 Demo 已编过。

#### sh-6 · 自举门槛 <a id="sh-6"></a>

远期。Guest：编译器 + 头 + `libBlocks` → 最小 ELF。

### 整柱验收

- [x] Manual 无「兼容 Linux/POSIX」主叙事  
- [x] 无公开双轨课设、无 App 头 `toy_*`、无 sockaddr 教程  
- [x] 非 ISO C 的 App API 为 Blocks 名（见 `Blocks/File.h` 等）  
- [x] C 库缺口书面可见（LibcGaps）
