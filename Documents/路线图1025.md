## 0 · duo-s · Milk-V Duo S 串口真机 <a id="duo-s"></a>

> **承接**：PR-B3 板包 + 2026-10-25～26 真机排障。  
> **已过 Definition of Done（壳+MMU+hello）**：厂商 U-Boot `bootelf` → `Sv39 on` → U-selftest → **`blocks>`** → **`run user` → Hello Ring3!**；`ls` RES。  
> **不做混进一刀**：Duo 上 GUI/HDMI；整盘改成 Pi `bootfs+BLOCKS`（会死 FSBL）；改厂商 U-Boot 源码（可改 env/脚本）。  
> **配方（勿改口令）**：

```text
# 宿主：mk-boot-sd.py → boot.sd（厂商原件 → boot.sd.vendor）→ LABEL=boot（勿 ck-pi-sd）
# 上电 run sdboot → bootm FIT → blocks>（勿抢壳）
# 回退抢壳：fatload … boot.scr → source；或 fatload Kernel.elf → bootelf
```

### duo-shell · 串口壳过关 <a id="duo-shell"></a>

✅（2026-10-26）。

- [x] 镜像 `milkv-duos-musl-riscv64-sd`；拨码 RV  
- [x] UART0 @ `0x04140000` reg-shift=2；picocom 115200  
- [x] `skip MMU` 避开 satp 后 `epc=0`  
- [x] VirtMin 壳：`help` / RES；`run user` 已挂名（无 MMU 时提示）  
- 排障：[MilkV-DuoS真机启动排障历程.md](过程/排障/MilkV-DuoS真机启动排障历程.md)

### duo-mmu · 真开 Sv39 <a id="duo-mmu"></a>

✅（2026-10-26 真机）。

- [x] `HalSatpWrite`：`dcache.call` → `satp` → `dcache.iall` + `sync.s` + `sfence`（virt 仍旧路径）→ 过 probe  
- [x] 去掉 `skip MMU`；见 `Sv39 on` + `after probe` + Mod Cpu  
- [x] C906 MAEE：叶子 PTE 加 PMA（C\|B\|SH）；AMO 不再 `cause=7`  
- [x] 启动 U-selftest：`enter U-mode` → `syscall ok` → `selftest ok` → `blocks>`  
- **禁止**：无证据跳自测装过关；为过关关串口

### duo-hello · `run user` 真跑 <a id="duo-hello"></a>

✅（2026-10-26 真机）。

- [x] Makefile：RiscV/Arm64 链 `User_hello_blob.o`；滤 HelloBlob stub  
- [x] C906：`HalSyncICache` / `HalPageTableLoad` 刷 cache；叶子 MAEE PMA  
- [x] ConsoleOnly：OnTimer 禁抢用户；`HalTlsSetBase` 勿改 tp；Own 不挡 fault UART  
- [x] **UP ConsoleOnly 须 `SchedulerStart`**（旧直跑 `SerialRun` → `CurrentTask` 空 → CoopDrain 假 done）  
- [x] 真机 `run user` → **`Hello Ring3!`**  
- 排障：V8–V16 见 [`过程/排障/MilkV-DuoS真机启动排障历程.md`](过程/排障/MilkV-DuoS真机启动排障历程.md)

### duo-block · SD→FAT <a id="duo-block"></a>

✅ TG+TS（2026-10-26）。★ → [duo-boot](#duo-boot)。

- [x] 板级 Block 后端：`Sd.c` SDHCI0 @`0x04310000`，PIO 只读（规格 + Linux cv18xx 复位）  
- [x] 真机：保留 `boot`（`fip.bin`/`boot.sd`/`Kernel.elf`）；另加 16GB FAT32，根上 `BLOCKS.ID` + `HELLO.ELF`，默认卷 BLOCKS，`exec HELLO.ELF`  
- **禁止**：格式化掉 FSBL/U-Boot 链（写扇区直接失败；`fip.bin`/`boot.sd` 卷标 ESP）

### duo-boot · 启动减摩 <a id="duo-boot"></a>

✅ TG（2026-10-26）。`bootdelay=1` + env nowhere → 卡上 `boot.scr` 减摩。

- [x] 卡上脚本：`HAL/RiscV/Board/milk-v-duo-s/scripts/{boot.cmd,boot.scr,mk-boot-scr.py}`（不改厂商树）  
- [x] ENV nowhere：不依赖 `saveenv`；FAT 有 env 时可另设 `bootdelay`+`bootcmd`（见 scripts/README）  
- [x] **真机**：`fatload … boot.scr` + `source` → `blocks>`；`vols` 见 BLOCKS；`exec HELLO.ELF` → Hello Ring3!  
- 冷启全自动 → 升格为 [duo-autoboot](#duo-autoboot)

### duo-autoboot · 上电直进（对标 Pi） <a id="duo-autoboot"></a>

✅ TG（2026-10-26）。真机上电不按键 → `blocks>`；无回归。★ → [rpi-8](#rpi-8)。

- [x] 真机：`bootcmd=run sdboot`；**无** `boot_targets`（不扫 `boot.scr`）  
- [x] 卡上方案：`scripts/mk-boot-sd.py` → FIT `boot.sd`（内嵌 Kernel @`0x80200000`；多 `config-*`）；厂商原件改名 **`boot.sd.vendor`**（勿删 `fip.bin`）  
- [x] ENV nowhere：不赌 `saveenv`；不改厂商 U-Boot 源码  
- [x] 验收：断电上电 → 无手动输入 → `blocks>`  
- **对照**：Pi 靠 distro 扫 `boot.scr`；Duo 对齐厂商 **`sdboot`→`boot.sd`→`bootm #config-<FDT_NO>`**

### duo-dtb · 传 DTB <a id="duo-dtb"></a>

✅ TG（2026-10-26；与 blocks-elf 同批）。**卡上通常无散装 `.dtb`**——在厂商 `boot.sd` FIT 里；仓内 `scripts/duo.dtb`。

- [x] `scripts/duo.dtb` + FIT `fdt-1`（`mk-boot-sd.py -d`）  
- [x] `boot.cmd`：`fatload … duo.dtb` → `fdt addr` → `bootelf -p`（无 dtb 则退回 `bootelf`）  
- [x] 手测：`Boot: DTB Memory Base=0000000080000000 size=000000001fe00000`；`config-sg2000_milkv_duos_musl_riscv64_sd`

## 0.5 · blocks-elf · Kernel.elf 上 BLOCKS（三架构） <a id="blocks-elf"></a>

✅ TG（2026-10-26）。口径：**应用卷根都有 `Kernel.elf`**；Duo 仍 `boot.sd` 上电；`boot.cmd` 从 BLOCKS 拉核。★ → [rpi-8](#rpi-8)。

| 架构 | 做法 |
| --- | --- |
| **X64** | `Runtime/RootFs/X64/Kernel.elf`（已有；`BLOCKS.ID` 同根） |
| **Arm64 Pi3B+** | **CK** / `ck-pi-sd`；`boot.cmd` `load mmc 0:2`（rpi-12 ✅） |
| **RiscV Duo S** | `ck-duo-sd`：`Kernel.elf` **只**在 BLOCKS；boot 删除副本；FIT 由 BLOCKS 打包（sdboot 限制） |

- [x] Duo：`ck-duo-sd`；`boot.cmd`←**mmc 0:4**；**boot 无 Kernel.elf**  
- [x] 口径：**BLOCKS = 应用卷，根含唯一 `Kernel.elf`**  
- [x] 手测：上电 FIT → `blocks>`；默认/`ls B:` 见 `Kernel.elf`；`ls A:` 无核（有 `boot.sd`/`duo.dtb`）  
- **禁止**：Duo 整盘改成 Pi 布局；再往 boot 放 `Kernel.elf`  
- **说明**：厂商 `sdboot`=`bootm FIT`，上电无法 fatload BLOCKS；FIT 内容从 BLOCKS 打包。抢壳 `boot.scr` 才是运行时 fatload BLOCKS。续作见 [duo-fatload](#duo-fatload)。

## 0.6 · duo-next · Duo 续作 <a id="duo-next"></a>

> **承接**：duo-s / blocks-elf ✅。串口真机已过；下列为板能力 / 启动减摩 / 体积。  
> **不做混进一刀**：改厂商 U-Boot **源码** / 重打 **`fip.bin`** / 持久改 `bootcmd`（ENV nowhere 常存不住）。  
> **★**：空；点名再开。建议顺序仅参考：fatload → sd-write → usb-kbd → slim → net。

| 方向 | 能感到什么 | 备注 |

| [duo-fatload](#duo-fatload) | 改核不用重打 FIT | **禁止**动厂商 bootcmd/fip；FIT→script |
| [duo-usb-kbd](#duo-usb-kbd) | USB 键盘打字 | HOST；无屏仍走串口回显 |

### duo-sd-write · SD 写 <a id="duo-sd-write"></a>

⬜。板上改文件 / 落盘。

- [ ] SDHCI0 写路径（规格 + Linux/U-Boot cv18xx 写时序；现 PIO **只读**）  
- [ ] 真机：`BLOCKS` 上创建/改文件可回读；勿写坏 `boot`/`fip.bin`  
- **禁止**：为「先跑通」关校验乱写 boot 分区；无证据缩超时

### duo-fatload · 上电真·fatload BLOCKS <a id="duo-fatload"></a>

⬜。上电即 `fatload mmc 0:4 Kernel.elf`；日常 `ck-duo-sd --blocks-only` 即可，**不必**重打 FIT。

- [ ] 杠杆仍是 **`boot.sd`**（已在换）：FIT 挂 `type=script`（内容≈现 `boot.cmd`）→ `bootm` 跑脚本  
- [ ] 真机：上电 → `blocks>`；改 BLOCKS 核再上电即新核；FIT 可长期不动  
- [ ] 回退：现「内嵌核」FIT / 抢壳 `boot.scr`  
- **禁止**：改厂商 `bootcmd` / 重编 U-Boot 进 `fip`；赌 `saveenv`  
- **风险**：Duo 这版 `bootm` 是否认 script（须真机验；不通另议，仍勿碰 fip）

### duo-usb-kbd · HOST USB 键盘 <a id="duo-usb-kbd"></a>

⬜。板上 USB Host 接键盘 → 壳可打字（串口仍可并存）。

- [ ] 板级 USB Host 探活（规格 / 现有 RiscV·X64 HID 门面对齐，勿另起缩水 API）  
- [ ] 真机：USB 键 → `blocks>` 输入；无键时串口不回归  
- **口径**：鼠优先铁律在有 HID 后适用；本刀先键。无 HDMI 不要求 Gui

### duo-net · 以太网 <a id="duo-net"></a>

⬜（量大）。板上有网。

- [ ] 现 `BOARD_HAS_NET=0`；开网须 MAC/PHY/DMA 对齐规格与姊妹板门面  
- [ ] 真机：链路上、可 ping / 最小套接字观感  
- **备注**：工作量大；勿与 sd-write / fatload 搅同一 PR

### duo-slim · ConsoleOnly 再瘦 <a id="duo-slim"></a>

⬜。体积优化，**非功能**。

- [ ] Duo/`BOARD` ConsoleOnly 少链 Font / Look 等无用模块  
- [ ] 验收：功能不回退（壳 / `exec` / MMU）；体积有可述降幅  
- **禁止**：借瘦身砍掉已过关路径或空 stub 顶门面

### rpi-8 · EL2 → EL1 <a id="rpi-8"></a>

⬜（自 1024；**现无 Pi 勿开 ★**）。曾只见 `*` 不见 `+`（死在 eret）→ 已撤。本刀单变量重做。

- [ ] 对照 ARM ARM：`SCTLR_EL1` RES1、`HCR`、`VBAR`、栈  
- [ ] 信标：`*` → `+` 在降级后仍成立  
- [ ] 不与 mailbox/MMU 同一 PR  
- **手测**：须 3B+；要不要 CK 收口写明

### rpi-9 · 真机放开 MMU <a id="rpi-9"></a>

⬜（自 1024 抄入）。依赖 memory（rpi-4 ✅）+ **建议 rpi-8**（现 MMU 写 `*_EL1`）。

- [ ] 去掉 `vmm: skip MMU (board)`；恒等映射 + `0x3F000000` Device  
- [ ] FB 页属性与 mailbox 缓冲一致（勿 cache 花屏）  
- [ ] 自测失败只打串口，不盲撞未映射高址  
- **禁止**：无证据缩超时 / 跳自测装过关  
- **手测**：须 3B+；桌面不花屏

与 Duo [duo-mmu](#duo-mmu) **分刀**（Arch/板不同）；经验可对照，代码勿搅。
