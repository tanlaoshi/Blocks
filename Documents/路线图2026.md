## 0 · duo-net · Duo 以太网 <a id="duo-net"></a>

> **承接**：1025 duo-next（usb-kbd ✅；slim ⛔）。板上有口，仓内 **无** 真机 MAC 驱动。  
> **硬件**：DTB `ethernet@4070000`（`cvitek,ethernet` / stmmac·DWMAC 系）。  
> **上栈**：RiscV 现仅 VirtioNet（`BOARD_HAS_NET`）；真机须新板驱动再挂 `HalNet*` / lwIP。  
> **不做混进一刀**：与 sd-write / USB / Pi 加固搅同一 PR；空 stub 顶「有网」。  
> **序**：net-1 → net-2 → net-3 → net-4 → net-5（单变量；前刀不过不点后刀）。

| 刀 | 用户能感到什么 | 主战场 | 验收 | 手测 | 风险 |
| --- | --- | --- | --- | --- | --- |
| **[net-1](#net-1)** | 串口证明 eth 控制器活 | 板 `Eth*`；clk/reset；对表 U-Boot/Linux cv181x | `Boot: Duo ETH …`；版本/ID 对规格 | Duo + 可不插线 | 中：基址/时钟 |
| **[net-2](#net-2)** | 插线 link | MDIO + PHY | 串口 `link up`（或等价） | Duo + 网线 | 中～高：PHY 型号 |
| **[net-3](#net-3)** | 帧能进能出 | DMA 环；Sv39 cache | 自发自收或抓包见帧 | Duo | **高**：DMA 一致性 |
| **[net-4](#net-4)** | 栈认这块 NIC | `HalNetInitialize` 真机路径；勿走 VirtioNet | `HalNetReady`；与 virt 门面同形 | Duo | 中：门面契约 |
| **[net-5](#net-5)** | **能 ping** | lwIP/DHCP 或静态 | ping 通网关/宿主机；可选最小套接字 | Duo | 中：地址/路由 |

### net-1 · MAC 探针 <a id="net-1"></a>

⬜。时钟 / 复位 / MMIO 探针。

- [ ] 对表 U-Boot / Linux `cvitek,ethernet` @ `0x04070000`；NOTES 写基址与时钟源  
- [ ] 串口可见控制器身份（版本/ID）；无帧、无 PHY 也可过本刀  
- **禁止**：未探针先开 DMA；猜基址

### net-2 · PHY / link <a id="net-2"></a>

⬜。依赖 net-1。

- [ ] MDIO 读写；识别板载 PHY  
- [ ] 插网线 → link up（串口可述）  
- **禁止**：无 link 假称 Ready

### net-3 · DMA 收发 <a id="net-3"></a>

⬜。依赖 net-2。

- [ ] TX/RX 描述符环；对齐规格与 Linux stmmac/cvitek 路径  
- [ ] Sv39 下 DMA 缓冲一致性（对表 duo-mmu / 规格）  
- [ ] 至少：发出帧 + 收到帧（环回或对端抓包）  
- **禁止**：无证据缩超时 / 盲重试风暴

### net-4 · HalNet 门面 <a id="net-4"></a>

⬜。依赖 net-3。

- [ ] `BOARD_HAS_NET=1`；真机 Bind，**不** `VirtioNetRegister`  
- [ ] 对齐 virt：`HalNetInitialize` / Ready / 收发包槽  
- **禁止**：半截 API；空函数声称有网

### net-5 · ping / 套接字 <a id="net-5"></a>

⬜。依赖 net-4。柱验收。

- [ ] 静态或 DHCP 拿到地址  
- [ ] 真机 ping 通；可选最小 UDP/TCP 观感  
- **备注**：课堂「板上有网」以本刀为准

## 1 · rpi-harden · 3B+ EL1 / MMU <a id="rpi-harden"></a>

> **承接**：[1024 rpi-desk](路线图1024.md#rpi-desk) → [1025](路线图1025.md) 交棒本档。主线桌面已过；本档只收 **rpi-8 / rpi-9**。  
> **稳态**：仍 EL2 + `skip MMU` + mailbox FB + 键鼠 + TTF。  
> **历程**：[Pi3BPlus真机启动排障历程.md](过程/排障/Pi3BPlus真机启动排障历程.md)。  
> **现无 Pi 勿开 ★**。

### rpi-8 · EL2 → EL1 <a id="rpi-8"></a>

⬜（自 1024；须 3B+）。曾只见 `*` 不见 `+`（死在 eret）→ 已撤。本刀单变量重做。

- [ ] 对照 ARM ARM：`SCTLR_EL1` RES1、`HCR`、`VBAR`、栈  
- [ ] 信标：`*` → `+` 在降级后仍成立  
- [ ] 不与 mailbox/MMU 同一 PR  
- **手测**：须 3B+；要不要 CK 收口写明

### rpi-9 · 真机放开 MMU <a id="rpi-9"></a>

⬜（自 1024）。依赖 memory（rpi-4 ✅）+ **建议 rpi-8**（现 MMU 写 `*_EL1`）。

- [ ] 去掉 `vmm: skip MMU (board)`；恒等映射 + `0x3F000000` Device  
- [ ] FB 页属性与 mailbox 缓冲一致（勿 cache 花屏）  
- [ ] 自测失败只打串口，不盲撞未映射高址  
- **禁止**：无证据缩超时 / 跳自测装过关  
- **手测**：须 3B+；桌面不花屏

与 Duo [duo-mmu](路线图1025.md#duo-mmu) **分刀**（Arch/板不同）；经验可对照，代码勿搅。
