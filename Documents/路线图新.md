### 启动加速（插队 · 已收） <a id="boot-accel-done"></a>

> 接 [fs-msc-defer](#fs-msc-defer)。✅ TG+TS；活 ★ 现为 [gui-wall-defer](#gui-wall-defer)。  
> 原则：进桌面前只保 **igpu/显示** + 键鼠 + **Os 卷** + **板载 COM1**；有线网 / HDA / 旁路盘后移；USB-UART **不进启动、不自动 Init**（普通设备 + 串口 App）。  
> **igpu** 开机保留（Present/blit）；不拆后移刀。  
> Gui 资源下一层见排队 [boot-gui-assets](#boot-gui-assets)（不抢 ★）。

**好处（已 ✅）**

- **进桌面更早可点**：网 / HDA / USB-UART 不堵开机；NUC 起不无谓扫 MSC。  
- **U 盘像正常外设**：热插拔只在桌面后；开机认棒与旁路慢认分开。  
- **无串口也能对表**：`*-BOOTDISK.LOG` / `*-OTHER.LOG` 分盘落；NUC 起拷 NUC、U 盘起拷 U 盘。  
- **多卷少看懵**：启动卷 / 启动盘徽章有口径；旁路卷只留灰色 DiskGUID。  
- **缺口（暂缓）**：U 盘起再拔启动盘应失根停住——尚未可靠，不挡本区收口。

#### msc-desktop-hotplug · 桌面后热插 <a id="msc-desktop-hotplug"></a>

状态：✅ TG+TS（NUC 起插拔 / U 盘起热插 OK）。契约：**只桌面 Worker**，不搅开机 AutoBeforeFs。  
- HotPoll：拔 → Release；插 → `Scan>0`（含 hub 子口）→ Claim/Mount；**~5s 节流**。  
- 无串口：各 BLOCKS 卷上按角色落盘（搜 `Fs: msc/`）：
  - `BOOT-BOOTDISK.LOG` / `RUNTIME-BOOTDISK.LOG` — **本次加载 EFI 的那块盘**上的 BLOCKS  
  - `BOOT-OTHER.LOG` / `RUNTIME-OTHER.LOG` — 旁路盘 BLOCKS 上的副本  
  - NUC 起 → 拷 NUC 的 `*-BOOTDISK`；U 盘起 → 拷 U 盘的 `*-BOOTDISK`（勿混 OTHER）
- Files：启动卷=OsTarget BLOCKS；启动盘=同 BootDisk 非 BLOCKS（ESP）；旁路卷仅灰色 disk/GUID。  
- **已收**：[usb-boot-unplug](#usb-harden-unplug)（U 盘起拔启动盘大窗 10s 关机）。

**日志序（手测对表）**

| 序 | 行 | 何时 |
| --- | --- | --- |
| 1 | `Fs: msc/1 skip (boot disk has BLOCKS…)` | **NUC/SSD 起** 开机策略 |
| 1 | `Fs: msc/1 claim (boot disk not mounted…)` | **U 盘起** 开机策略 |
| 2 | `Fs: msc/2 boot-claim skipped` | NUC 起（无开机扫盘） |
| 2 | `Fs: msc/2 boot-claim begin` → `ok` / `empty` | U 盘起开机认棒 |

## 钉核策略文档落地 <a id="sched-pin-doc"></a>

状态：✅。路线图表 + `Scheduler/Start.c` 策略块 + `Kernel.c` Input/CPU2；不改行为。  
门槛五门闩交叉引用见 [input-f1-gates](#input-f1-gates) / `Tasks.c` 头。

主战场：`SchedulerStart` 钉核段（`Core/Scheduler/Start.c`）+ BringUp 谁 Create（`Kernel.c`）。  
按任务名首两字母匹配（`sh`/`gu`/`in`/`wo`）。

### 默认桌面（非 ConsoleOnly；`HalPinInteractiveToBootstrap==0`）

| 逻辑 CPU | 钉谁 | 优先级要点 |
| --- | --- | --- |
| 0（BSP） | idle0、**Worker**；中断/后台泵 | UP 时 Worker 提到 `SHELL`，避免被饿死 |
| 1（AP，SMP≥2） | **Shell**、**Gui** | `SCHED_PRIORITY_SHELL` |
| 2（AP，Count≥`HAL_INPUT_CPU_MIN`） | **Input**（`KernelTrySpawnInput`） | `DEFAULT`；独占 drain |
| 其余（含四核的 CPU3） | 各核 idle | — |

门槛现 `HAL_INPUT_CPU_MIN=4`（[input-f2-threshold](#input-f2-threshold)）：1/2/4 核形态；三核及以下无 Input，`YieldForPollInput` 自 drain。  
SMP=1：交互与 Worker 都在 0。Input 仍钉逻辑 CPU2（有专核时）。

### 强制钉 BSP / 串口子集（[input-f3-console](#input-f3-console)）

| 旗标 | 作用层 | 现实现 |
| --- | --- | --- |
| `HalConsoleOnly` | **选路**：Virt 表 + 只 Create Shell（无 Gui/Worker/Input） | x64=0；arm/riscv=`!FB` |
| `HalPinInteractiveToBootstrap` | **钉核**：Interactive/Input 全改 CPU0（盖过 `HAL_INPUT_CPU_MIN`） | 三架构均 0 |

用途：串口壳；virt 定时器只在 BSP 时交互钉 AP 会永 WFI。  
与 F2 门槛正交：ConsoleOnly 时根本不 Create Input；Pin 只改亲和性。

### BSP 首任务

`SchedulerStart` 只从 **Affinity==0（或未钉）** 里挑 First，再 `Online`→Enter；钉在 AP 上的任务由各核 idle/调度接。

**好处**：查假死/饿死/无 tick、改 SMP 时对表即可；改策略另刀。
