# 拉平地基（2026-10-24）

> **目的**：selfhost 叙事刀（sh-1′…sh-sys）已落 main；代码与契约仍有「半截 / 双轨 / 硬编码」。  
> 本档把**不平处**钉死，拆成可独立验收的 PR，再谈 sh-6 自举。  
> **活 ★**：[`路线图1024.md`](../路线图1024.md)。本稿只规划，不代替 JX 刀单。  
> **正本 Manual**：身份与红线见 [`Manual/App/README.md` §0.1](../../Manual/App/README.md)。

## 0. 一句话

**拉平 = 同一类事只保留一条契约，且契约写在规格位（PKG / ABI / 文件头），不写在启发式名单或排查注释里。**

不是：再开一波修鼠启发式、复活 GUIDEMO、对齐 Linux。

## 2. 不平处（代码实证）

按「用户能感到 / 维护者会踩雷」排序。每条都带路径；改之前先对规格/PKG，禁止猜。

### 2.1 开窗认窗：PKG 与硬编码双轨（高）

**契约本应唯一**：`PKG.TXT` 的 `window=yes` → `ProcessAppTakesWindow` → exec **勿** `CoopDrain`（异步），否则 GUI 事件循环把壳钉死。

**现状**：

```text
StoreReadAppDesktopMeta(Id) 成功且 WindowYes → 1
否则 → ClassElfTakesWindow(硬编码 snake/taskmgr/chat)
```

- 实现：`Kernel/Core/Process/AppFont.c`（`ClassElfTakesWindow`）  
- 回落读盘：`PackageMetadata.c`（Apps 无包时读 `Store/packages/<id>/PKG.TXT`）— **合理，可留**  
- **不平**：`Runtime/Store/packages/chat/PKG.TXT` **没有** `window=yes`，靠硬编码名单保 Chat；名单是启发式债  

**拉平目标**：认窗 **只信 PKG**（+ Store 回落）；删硬编码表；Chat（及一切开窗 App）PKG 补 `window=yes`。

### 2.2 关窗 / exit：USER 与系统窗契约已分叉，注释仍写 GUIDEMO（中）

**现状（保留的对的）**：

| 路径 | 行为 |
| --- | --- |
| 轻量关（USER/Shell/Settings…） | 擦矩形 → `RestoreWindowsInFootprint`（抄拖动脚印）→ 任务栏 → `PresentFlush` |
| ExitUser 最后用户 | `CloseAllUserWindows` 后 **不再** `ThemeScene`（避免二次 Flush 饿死 xHCI） |
| 点击 | `GuiPresentDeferPause` 包住 `HandleClick`（与图标拖一致） |

实现：`Close.c`、`Wait.c`、`Pointer.c`、`SystemProcess.c`（exec 外包 `DeferPause`）。

**不平**：

1. 文件头 / 注释大量「GUIDEMO」叙事 — Demo 已删，应改成**契约句**（脚印 / Busy 外 Backup / Exit 勿 ThemeScene）。  
2. `ClickDesktop` 与 `SystemProcess` 两套 WaitPrompt/ShowPrompt 文案平行 — 行为已对齐，缺**一处规格说明**（可放 `Process.h` 或 `Gui` 私有头 10 行）。  
3. `HalPlatformIsVirtSerialConsole()` 在 **x64 恒 0**（`HalPlat.c`），但 `ProcessExec` 仍写「virt 全形状 drain」— 注释/条件对 x64 **误导**，易让后人以为图形 QEMU 会 drain 开窗 App。

**拉平目标**：注释与 x64 现实对齐；关窗不变量写进 `Close.c` / `Compose.c` 头，不绑已删 Demo 名。

### 2.3 公开脸仍双名（中）

| 双轨 | 现状 | 风险 |
| --- | --- | --- |
| ~~`Net.h` / `ToyNet.h` 双头~~ | **已拉平**：只留 `Net.h` + `libNet.a`；`ToyNet.h` 已删 | — |
| `<pthread.h>` 薄封装 → `Thread*` | Smoke/ThreadDemo 仍教 pthread 名 | 与 §0.1「非 ISO 不走眼熟名」摩擦 |
| `Blocks/syscall.h` 的 `blocks_fork` / `blocks_open`… | 与 `ProcessFork` / `FileOpen` 并存 | 三层名字（SYS / blocks_* / Process*） |

**拉平目标（分阶）**：

1. **文档与范例**：只示范 `Net.h` / `Process*` / `Thread*` / `File*`。 ✅ Net  
2. **头文件**：只留 `Net.h`；不留 `ToyNet.h` 转发。 ✅  
3. **pthread**：保留实现供旧 Smoke；Manual 标明「兼容垫片，新课只用 Thread*」；不扩 pthread 面。  
4. **blocks_***：视为 CRT/汇编薄封装，App 文档不教；汇编 `.S` 可继续用 SYS_*。

### 2.4 Class / Store 教学面不齐（中）

- Class 仍堆：HELLO、线程/管道/net、DIRDEMO、SOCKDEMO…（窗 Demo 已删）。  
- `build.sh` 与 catalog 已去 guidemo 三件套；工作区若再现空包目录，属同步残留，拉平刀应 `rm` 干净。  
- `demopack`/`sun8` 曾为 guidemo 依赖故事服务 — 可留作 store 依赖课，但 combo 提示勿再写 guidemo（已改 snake）。

**拉平目标**：写一张「Class 白名单」表（保留 / 可选 / 禁止再加窗 Demo）；Makefile/`build.sh` 与表一致。

### 2.5 文档双树（低～中）

`Manual/` 为正本（Coding.md 已写）；`Documents/手册/` 过渡副本仍在改。  
开课 ABI / 学生卡仍出现「非完整 POSIX」说明 — **允许作「不承诺」边界**，禁止写成「兼容 POSIX」。

**拉平目标**：新改只动 `Manual/`；手册副本要么脚本同步要么标明废弃时间。

### 2.6 libc 加厚 vs 自举（低，排在后面）

`LibcGaps.md` P0/P1 未勾。  
**红线**：加厚时禁止顺手恢复 `open`/`fork` 公开脸。  
**顺序**：地基契约（2.1–2.4）平了再开 LibcGaps P0；P0/P1 够用后再 sh-6。

### 2.7 明确不拉平（禁区）

| 不做 | 为什么 |
| --- | --- |
| 复活 GUIDEMO/WINDEMO/BLITDEMO | 已产品决策删除 |
| 为修鼠再堆 Present 启发式 | 标准优先；关窗已抄拖动脚印 |
| 改 SYS 号值 / 对齐 Linux 号表 | ABI 冻结 |
| 一夜删光 `pthread.h` / `sys/socket.h` 致 Chat 全红 | 「假彻底」 |
| 在未平契约时开 Guest 自举 | 会把硬编码焊进工具链 |

## 4. PR 拆分（建议序）

每个 PR：**可单独 merge、可单独手测、不依赖「下个 PR 来擦屁股」**。  
依赖箭头：先 → 后。

### PR-A · 认窗契约唯一（地基核心）

**改什么**

1. `chat/PKG.TXT`（及任何开窗但缺字段的包）补 `window=yes`。  
2. 删除 `ClassElfTakesWindow`；`ProcessAppTakesWindow` 只返回 `Meta.WindowYes`。  
3. `Process.h` / `AppFont.c` 文件头写清：Id 提取规则（`Apps/<id>/` 与 `Class/<ELF>` 基名）+ PKG 回落。  
4. 断言或 Debug：开窗 App 若 PKG 读失败 → 串口一句 `takes_window: no pkg`（可选，勿刷屏）。

**不改**：CoopDrain 算法、Gui 合成。

**验收**

- [ ] `exec` / 桌面图标：TaskMgr、Snake（已装）、Chat（若从 Store 跑）仍异步，鼠不死。  
- [ ] HELLO 仍 CoopDrain、退完回提示符。  
- [ ] `rg ClassElfTakesWindow` 无命中。

**风险**：漏补 PKG → 开窗 App 被 drain 卡死。减险：merge 前扫全部 `Store/packages/*/PKG.TXT`。

### PR-B · 关窗 / exec 注释与 x64 现实对齐

**改什么**

1. `Close.c` / `Wait.c` / `Pointer.c` / `SystemProcess.c`：去掉 GUIDEMO 专名，改契约句。  
2. `ProcessExec`：x64 上 `HalPlatformIsVirtSerialConsole()==0` — 注释改为「仅当平台函数为真才 drain 开窗 App；x64 桌面恒异步」。  
3. 可选：抽 `ExecWindowAppBegin/End`（WaitPrompt + DeferPause）供 Shell 与 Desktop 共用 — **若超 1 屏 diff 则拆 PR-B2**。

**验收**

- [ ] 关 Shell、Settings、TaskMgr：鼠跟手。  
- [ ] 无行为变化（纯文档/注释/薄封装）。若有 B2 抽取：行为与抽前一致。

**风险**：低。禁止「顺手」再改 PresentFlush ↔ Present。
