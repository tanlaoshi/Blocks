# Blocks Manual

> 仓库根下的**读者手册**（身份闸）。排期 / 日档 / 柱归档仍在 [`Documents/`](../Documents/README.md)，不进本树。

## 你是谁 → 去哪

| 身份 | 入口 | 一句话 |
| ---- | ---- | ------ |
| **A** 写 App | [`App/`](App/README.md) | ELF、UI、文件、网络、商店包 |
| **B** 写驱动 | [`Driver/`](Driver/README.md) | Probe / Bind / 匹配 / 模板 |
| **C** 读源码做研究 | [`System/`](System/README.md) | 字典、开机、目录树、syscall 真源 |
| **D** 参与贡献 | [`Contribute/`](Contribute/README.md) | 接手、编码规范、改 ABI 同步清单 |
| **E** 学生 / 作业 | [`Course/`](Course/README.md) | 速查卡、冻结面、课堂作业 |

共用五分钟上机：[`START.md`](START.md)。

## 与 Documents 的分工

| 树 | 管什么 |
| -- | ------ |
| **`Manual/`** | 给人读的手册（本目录） |
| **`Documents/`** | 日档路线图、月进展、过程归档、柱规格、同步备忘 |
| 仓根 [`原则与学习记录.md`](../原则与学习记录.md) | 从 OVMF 逐段 review 的长叙事（System 入口会链到） |

取材自原 `Documents/手册/`、`Documents/规范/`、`Documents/项目/技术手册.md`；迁移期两边可能并存，**读者优先认 Manual**。
