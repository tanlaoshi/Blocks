# 红线（App）

1. **勿**链宿主 glibc；**勿** `-pie` / `-fpic`。用本目录 Makefile + BlocksSDK。
2. **ISO C99** + Blocks API（`<Blocks/…>` / `<Ui.h>` / `<Net.h>`）。勿再写 `sockaddr` / 假 POSIX 双轨课设。
3. 开窗：必须 **`Apps/<id>/` + `PKG.TXT` 且 `window=yes`**。  
   **禁止**扁平 `Apps/FOO.ELF`（无包 → CoopDrain → 开窗关不掉、桌面钉死）。  
   盘上 ELF 名 **8.3 大写**。

链哪一层：

| 层 | 库 | 头 |
| --- | --- | --- |
| 底 | `libBlocks.a` | ISO C + `<Blocks/…>` |
| 窗 | + `libUi.a` `libGraphics.a` | `<Ui.h>` `<Graphics.h>` |
| 网 | + `libNet.a` | `<Net.h>`（`NetConnect` 主机序） |
